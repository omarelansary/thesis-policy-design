# Title: the slot-5 negative is a four-way conjunction and so says almost nothing about prior art

**Objection.** 03 L69 reads "Memory that chooses or pre-loads tool definitions across sessions, with a bill measured: NONE FOUND", and concludes "the core of REQ-U21-04 is OURS". The row requires four properties at once: memory, choosing or pre-loading tool definitions, across sessions, and a measured bill. Almost no paper in the field reports a bill (the map's own rows for MemTool, ToolMem, MemToolAgent, MCP-Zero and RAG-MCP report removal ratios, accuracy or prompt tokens). So the last conjunct alone makes a "none found" certain, and it does not discriminate. What it licenses is "no source found that measures a bill", not "no source found that does memory-informed tool offering". The nearest stored items (MemTool L64, ToolMem and MemToolAgent L65, 2607.09493 L66, Copilot's usage-statistics core L53) are classed as "prior results", but the row does not say which conjunct each one fails. The reader cannot tell how close the nearest prior art is.
The same row is used in 02 (L30, "no source measuring memory-informed offering with a bill was found") to call the supervisor's novelty claim "consistent".

**Evidence.** 03 L64-L66, L69; 02 L30; EXT-0228 L61 ("Based on tool usage statistics and performance data, we identified a core toolset of 13 essential tools"), which is usage-informed offering at aggregate level.

**What would resolve it.** Split the row into its conjuncts in a table: for each nearest item, say which of {memory, tool-definition choice, across sessions, per user or role, bill} it has. State the gap as the exact missing conjunct. Re-word 02 L30 and the novelty sentences in 04 and 06 to match.
