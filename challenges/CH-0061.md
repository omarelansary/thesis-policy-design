# Title: "A needed tool is absent" is used for two different constructs, and the sources measure neither cleanly

**Grade: SERIOUS (it decides which source counts as "nearest" and what pilot 2 must manipulate).**

**Objection.**
Three situations are folded into "absent":
(a) the needed tool exists in the catalogue but is **hidden** from the model's view (the case our R4 recovery depends on; MCP-Zero, vendor tool search, SING test this, always with a target present);
(b) the needed tool exists **nowhere** (the right behaviour is to say so or answer from knowledge; KAIST's API Replacement is the nearest, with a similar wrong tool visible);
(c) the tool is **visible** but the model does not call it (LOMEKWI section 6).
`05` row B uses (b) and (c) as "nearest" evidence for a question that is (a). In MCP-Zero every test item has a target tool in the collection (EXT-0101 lines 71-72, "requiring models to retrieve the target tool"); the "no appropriate tools exist" branch is design text only (EXT-0100, EXT-0101 per steward). So **(a) with instruction is measured (accuracy of retrieval), (b) with a search channel is not, (c) is measured but is a different behaviour.** The v3/v4 E2 wording "Remove one needed tool per task" (v3 `04` row E2; `01` line 102) does not say whether the tool is removed from the model's view only (a) or from the catalogue too (b). If removed from the catalogue, a search cannot succeed and the experiment measures abstention behaviour, not whether search pays; if hidden only, it measures (a). Pilot 2 as described in `05` section 2.1 ("uses it when no visible tool fits") is (a); the gap sentence "absence recognition when the model is not asked a feasibility question" is (b). They need separate cells and separate falsifiers.

**Evidence.** EXT-0101 lines 64-75; `05` section 1 row B gap column; v3 `04` line 38; `01` line 102 (`design/package-v4/01-supervisor-brief.md`).

**What would resolve it.** Define (a), (b), (c) in `05` and E2, state which each source informs, and say which pilot 2 cells correspond to which. Answerable now.
