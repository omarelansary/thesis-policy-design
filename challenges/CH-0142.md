# Title: Pairing does not make scorer error non-differential when the arms differ in the number and pattern of tool calls, which is what V5's arms differ in

**Objection.** The closing sentence of s6 says "paired arms on the same tasks are needed so that scorer error falls on both arms". Pairing removes task difficulty; it removes scorer error only if the error is independent of the arm. V5's arms differ by design in tool-call behaviour: extra search calls under deferral, seeded tools called or not, "answer without a tool" as a P3 outcome class. Several scorers in the register react to exactly that:
- BFCL multi-turn: the authors' blog says "Response-based evaluation tends to penalize models for these redundant actions, even if they do not affect the overall task outcome" (SUM-0070 B3, blog L807-810), and Epoch's worked case is that a model which checks first and makes no call "will fail the turn entirely" (SUM-0070 B9; `multi_turn_miss_param_143`). An arm that searches first is penalised by the scorer, not by the policy.
- MCP-Atlas: the judge reads the final response only, never the trajectory (inspector I1, `score_claims.py`), so differences in how the answer is phrased or truncated after more tool rounds enter the score.
- tau2-bench: malformed tool-call JSON and empty replies "drop out of the denominator" (#672), so an arm that makes more calls has more chances to be dropped, and the drop is scored 1.0 in the reporter's demonstration (SUM-0077 E9; a demonstration with a stubbed model, not a leaderboard effect).
- MCPMark: 559 of 11,314 runs end without a verdict and count as failures (issue #272), so a policy that lengthens runs shifts failures into this class.
So scorer error here is differential in direction, and the "both arms" argument can mask a bias in either direction of the P3, P2, P4 and E2E contrasts.

**Evidence.** `17` s6 L153; SUM-0070 B3, B9; SUM-0077 E9, E17; inspector I1 item 1(f); `05` s2 P3 outcome classes.
[F] the scorer behaviours as reported on the stored pages. [I] that V5's arms exercise them. [U] the size of the effect; no run has been made.

**What would resolve it.** Replace the sentence by: pairing controls task difficulty only; for every chosen scorer, run a scorer-sensitivity check on the pilot (score each arm's runs with the native scorer and with a trajectory-aware or state-only check, and read the discordant pairs by hand), report how many failures are of the classes above, and treat verdict-less runs as a separate category in both arms.
