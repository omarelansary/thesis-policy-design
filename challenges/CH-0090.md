# Title: the NONE FOUND rows cite support that the search log itself does not give them

**Objection.** Four NONE FOUND verdicts in the reuse map, and the claims built on them, are stated more strongly than `inputs/search-log-20261022.md` supports.
1. Slot 4, multi-step narrowing (03 L58): support is "scout group 2; both blind instances". The search log (L7) lists group 2's queries: Executor, AgentCore, Docker, GitHub MCP, and one combined framework query. None concerns hierarchical, coarse-to-fine or multi-stage tool retrieval. The same log lists what group 2 did not reach (mcp-use, Composio, Semantic Kernel, smolagents, CrewAI, AutoGen, OpenHands, Cline, Goose). So the group that "found none" never asked the question.
2. Slot 5, memory-informed offering (03 L69): support is "scout group 3; both blind instances; V4 04 section 4". Group 3 logged one query on that topic (L8). The scout prompt asked for Anthropic Agent Skills and for mem0, Letta, Zep and LangMem "specifically where memory is used to choose or pre-load tools" (`scout-prompts-20261022.md` L32). The log shows no skills query, and lists Mem0, Letta and Zep only as "named by scouts, not stored" (L20).
3. Slot 9, a vehicle with sessions, a gap, a large catalogue and cache fields (03 L108): support is "scout group 4". The log (L9) says Toolathlon, MCP-Atlas, Inspect AI and LiteLLM usage fields were "Not examined".
4. Slot 7, a recommended cap on discovery calls (03 L89): one logged query (L9).
Both blind instances are cited as support in rows 58 and 69, in 01 C13 (L51) and in 02 (L30). The search log (L11) says their statements "cover the allow-list in `blind-prompt-20261022.md`" only. They searched stored files, not the open literature. A negative from a closed list does not support "not found in the places searched" for the open web.
The qualifier "in the places searched" does not rescue the rows: the places are not documented for these topics.

**Evidence.** Search log L3 ("The only support for any 'not found'"), L7-L9, L11, L20; 03 L58, L69, L89, L90, L108; 01 L51; 02 L30; `inputs/scout-prompts-20261022.md` L32 (not re-read in full by me; quoted via grep). No search of my own was run (none authorised).

**What would resolve it.** For each of the four rows, either (a) add the actual query text, place and date of a search that targets the stated topic, with the hits seen and why each was rejected, or (b) reword the verdict to "not searched" or "leads only" and drop the blind instances from the support list. The headline sentences that rest on these rows (04 section 1 sentence 3 and section 8, 06) would then say "no source found in a limited search", not "a bounded negative".
