# Title: the power table reproduces; its conclusion is roughly right but is stated coarsely, the "error" in the draft is a convention, and several assumptions push the real requirement upward

**Grade: MINOR.** I reproduced the arithmetic; I mark where the conclusion is stated more precisely than the assumptions allow.

**Recomputation (by hand; I had no computation tool).** One-sided paired noninferiority, normal approximation, variance of the paired difference approximated by the discordant rate q = 0.20, alpha 0.05 (z 1.645), power 0.80 (z 0.842): n = (z_a + z_b)^2 q / (delta - loss)^2 = 6.18 x 0.2 / ... gives 124 (delta 0.10, loss 0), 495 (0.05, 0), 1,371 (0.05, 0.02, with variance q - D^2 = 0.1996). Bonferroni over six (alpha/6, z 2.394): (3.236)^2 = 10.47: 209, 838, 2,322. All six figures in 02 section 7 agree with mine to within rounding. Using the variance under the null (q - delta^2) gives about 120 and 491 for the first two; immaterial.

**Objection.**
1. **The "error" in the earlier draft is a convention.** 03 section 2 item 2 says the draft "used two-sided tests for a one-sided problem" and gives 160 and 1,700. Those are the one-sided alpha = 0.025 numbers (z 1.96: 157 and 1,741), i.e. the lower bound of a two-sided 95% interval, which is what "paired intervals" and "lower confidence bound" in v3/v4 refer to. `alpha` is "unset" in 02's own preface. The correction is a choice of alpha, not a fix; with alpha = 0.025 the v4 table grows by about 27%. Say so.
2. **q = 0.20 is unsupported and probably low.** No stored source gives arm-versus-reference discordance. From EXT-0053: at k=32 only 75.3% of tasks are fully reachable and unreachable tasks essentially never pass (1 of 1,905 attempts); if the reference passes 40-45% of those, reachability alone produces about 10% discordant pairs before any other difference. q = 0.30 multiplies every n by 1.5 (186, 742, 2,057 for one contrast). This strengthens the lead's conclusion but the table should carry the sensitivity.
3. **"Loss 0" is the best case.** Every restricted arm in Table 7 loses about 7 to 31 points to curated (EXT-0053; my subtraction of the printed cells); the 0.02-loss row is the only one with any loss.
4. **Six contrasts is not tied to the arm table.** Base arms are six (search-only, +P1 L1, +P1 L2, +P3, static core, navigated), each doubled by "ordered-core arms" when a need estimator exists, plus the matched stage-inclusion pairs. With 12 contrasts alpha/12 (z 2.64) gives about 970 for delta 0.05, loss 0 (my estimate). CH-0040 (a) asked for the enumeration.
5. **Strata.** The IUT logic (an arm is feasible only if all stratum tests pass) needs no multiplicity correction but needs a *joint* power of 0.80: with three strata and independent tests the per-stratum power must be about 0.93 (z about 1.46), raising n per stratum by about 56% over the table [I]. "Each stratum needs this many tasks separately" is right as a per-stratum count and understated as a design requirement.
6. **Confirmation split.** S6 confirms the chosen arm once on the test split; the test split needs its own n for the mean and strata; the table counts one split.
7. **Cost side not powered.** S and the epsilon rule need paired token-cost contrasts; token cost per trajectory is heavy-tailed. No sample size is given for these, so the dependence of S on n (CH-0050) is unquantified.
8. **Conclusion wording.** "Unaffordable for margins of about five points or less on that vehicle" is true for strata (the 150-task subset has 50 per depth stratum; even delta 0.10 needs 124 per contrast), for six contrasts (838 > 750), and for any alpha = 0.025 with q = 0.30. It is not true under the stated assumptions for a single mean-level contrast on the 750-task slice (495 <= 750), and the lead should say which case is meant. Whether 750 tasks can be run for every arm is a cost question not addressed.
