# Title: MCPMark "about 51 tasks" mixes paper-v1 counts with a later repository state, and omits Playwright

**Objection.** s7 P4 gives MCPMark local services as "Filesystem and Postgres, about 51 tasks" with "a known exploit on 12 of 28 Postgres tasks". The paper (v1, 2025-09) counts 30 Filesystem and 21 PostgreSQL tasks (`v5-mcpmark-2509.24002.txt` L568-569), which gives 51. The issue #278 tested 28 Postgres tasks at commit cd45b7f (`v5-bm-e11` L49, L57), i.e. a later repository state with more Postgres tasks than the paper's 21. The "Verified" task version the s5 row says is current has no count. So the pool "51" is not the pool a run would use, and the exploit rate and the pool come from different versions (s5 CH-0151 note says this mismatch exists for MCPMark logs, not for task counts). The paper also lists Playwright (25 tasks) among local services (L666), which s7 does not consider for P4 although browser pages are large tool results; this may be intentional (not checked).

**Evidence.** [F] as cited. [U] the current repository's counts and the "Verified" version's.

**What would resolve it.** Give the version and count for the pool or mark it as the paper's; say whether Playwright was considered.
