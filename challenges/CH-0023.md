# Title: the free tolerance epsilon is the success/cost trade-off dial and is not derived from delta: C-A is a one-parameter family unless that is fixed

**Grade: SERIOUS (it bears directly on checklist item 1, "a family with open slots may be the context; the candidate must fill the slots or say which minimal decision is missing").**

**Objection.** A1 Step 1 is a pure token-cost rule; success enters only through Step 2's `M(F) = sum p_hat*q_hat <= epsilon`. `M(F)` is an expected count of unrecoverable needs per session, not a success loss, and `epsilon` is a human value (DPR-0004 section 3.4(i)) unrelated to the F1 margin `delta` (population success within `delta` of `pi_ref`, section 6.1). The size of `F` is monotone in `epsilon`; so the output of A1 is a path of surfaces indexed by `epsilon` (and by `T_bar`). Either `epsilon` is swept, in which case the evaluated object is a frontier (DPR-0001 F4: "a frontier, not a policy"; REQ-O14-08), or it is fixed by a human number with no stated link to `delta`, in which case the F1 result depends on a second unanchored margin. A1 also has no distraction term, so a larger `F` may cost success (EXT-0053: flat costs 8 points on one model/one draw, V6), and `epsilon` cannot represent that. DPR-0004 says it "fills every node"; the node A1 has an open dial that decides the central trade-off.

**Evidence.** DPR-0004 sections 3.4(i), 4.2 A1, 6.1, 6.5(5); HYP-0014; DPR-0001 F1/F4 (package A, A7); EXT-0053 via SUM-0003 V6.

**What would resolve it.** Either (a) a stated mapping from `delta` (and a success cost per unrecoverable miss estimated on separate data) to `epsilon`, with the estimator named, or (b) the answer to checklist item 1 changed to "C-A is a one-parameter family; the minimal missing decision is the rule that fixes `epsilon`", and the pre-registration states how the claimed `epsilon` is chosen before the run.

**Response (proposer).** [round 1 reply, verbatim excerpt] "PARTIAL: CH-0023 (epsilon := delta as sufficient conservative mapping via expected loss <= M(F)*y_need, y_need<=1; tighter mapping OPEN)." [rounds used: 1 of 2]

**Round 2 (challenger): DOWNGRADE serious -> minor.** The union bound `P(failure from deferral) <= M(F) * y_need <= M(F)` is valid when `p_hat`, `q_hat` are unbiased, so `epsilon := delta` removes the second free margin; my "family" point is answered for the dial. Residuals: (i) it spends the whole margin `delta` on deferral misses, leaving none for other success changes (distraction, extra turns), which is conservative only if `p_hat`/`q_hat` are unbiased (see CH-0024, maintained); (ii) DPR-0004 sections 3.4(i) and 6 item 5 still list `epsilon` as a separate human decision (stale).

**Outcome.** partly resolved; residual minor.
