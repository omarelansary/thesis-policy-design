# Title: PL-3's whole-definition hash is a contract-free check, and the evidence cited for it is by analogy

**Objection.** PL-3 drops a seed whose "definition (hash)" changed. The nearest checked result on drift detection, G25 (SUM-0060), reports that "contract-free CI probes produce 40% false positives" while checking only the assumptions a skill depends on raised none; a hash of the whole definition is a contract-free probe (any wording change drops the seed). Dropped seeds fall back to discovery D, which has a bill cost, so false drops are not free. `15` s4.5 cites G25 in the same breath but PL-3's evidence column does not, and the scout's own G25 reading ("check by the assumptions it depends on rather than by any difference") and its G26 hash recommendation disagree. Further limits: G16 is an absence in one page ("no versioning or hash"); G26 (rug-pull pinning, a community blog, "1 of 8 changes" caught by dialog pinning) is an unfetched search summary and low-quality by the scout's own label; G24's 13.7% and 14.4% declines are for two of twelve models, measured between an early and a late evolution stage, with operators that include tool addition and integration (SUM-0060 G24), which would not invalidate a seed. `15` s4.5 writes "Changed tools hurt" and "task-fulfilment scores fell from about 7.2 to about 6.2" without these qualifiers. G25 is about skill documents, not MCP definitions, as `15` notes.

**Evidence.** SUM-0060 G24, G25, G16; scout G rows G25, G26; `15` s4.5, s6 PL-3.

**What would resolve it.** State that the hash is a conservative check with unmeasured false drops; add false-drop rate and D cost to PL-7's measures; add the two-of-twelve and early-to-late qualifiers to the G24 sentence.
