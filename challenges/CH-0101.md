# Title: C7 (74.7%) is a share of a reconstructed cost in coding-agent sessions, and is not a measure of the tool block

**Objection.** 01 C7 (L45) and 03 L80 say the harness base was "74.7% of cost" and 03 says "billed cost". The source: Table 1 is a cost attribution "reconstructed from stored transcripts under a calibrated tokenizer" over 1,212 child sessions; "usage fields exact, component attribution measured, hidden-thinking and cache attribution inferred"; the text adds that cache creation and reads are about 80% of the actual bill with 8.7% unattributed (L202-L204, L231-L234). The 74.7% therefore is a share of the reconstructed total, with the cache part inferred. It covers the Claude Code-style system prompt plus tool definitions together, so it says nothing about the tool block alone (03 admits this). It is the evidence for "the fixed prefix carries the bill" (02 L29, 04 premises), and the REQ-O21-08 requirement is any kind of agent, not coding agents. The same study's 38.4% output-compression cut raising paired cost by 6.8% is correctly marked as one study.
Pointers and numbers (74.7, 3.3, 1.3, 6.0) match the stored text; this is a wording and scope point, not an error.

**Evidence.** L/pdf-tokennotcost-2607.12161v5.txt L200-L222, L231-L244; 01 L45; 03 L80; 02 L29.

**What would resolve it.** Say "share of the study's reconstructed cost (cache attribution inferred)" in 01 C7 and 03 L80, and drop "billed".
