# Title: Four small statements go beyond what the cited pages show

**Objection.**
1. *s4:* "No candidate reports the bill V5 needs ... only ATRBench and Claw-SWE-Bench state cache accounting." The same document's cards and precedents show Toolathlon with "cost with caching on, no hit rate" (SUM-0076 D23), SWE-ContextBench with cache-read tokens above 97% of consumption (D30), and the tau2-bench-Verified leaderboard with costs "including prompt caching discounts" (SUM-0077 E7). The sentence is right only for per-request fresh/cached/write splits; as worded it contradicts the cards.
2. *s5 MPT licence "CC BY-NC-SA 4.0".* That is the anonymous repository's statement (inspector I2 item 4). The paper says the paper itself is CC BY 4.0 and the release has "terms compatible with each" source (SGD CC BY-SA 4.0, DuRecDial 2.0 CC BY-NC-SA 4.0, HomeBench without a licence file; SUM-0072 C3). The data licence is therefore not one stated licence.
3. *s5 ATRBench "order only, no time".* Absence by grep (SUM-0073 D28 note; the paper says themes are "temporally ordered"). Write "no wall-clock gap found by these searches".
4. *s5 MCP-Bench "0.668-0.692 (compressed, ceiling)".* The values are an LLM-judge plus rule-based composite averaged over settings, not a pass rate (SUM-0069 A32); a compressed composite near 0.7 is not a ceiling in the sense of s1.4.

**Evidence.** As cited. [F] the pages; [I] that each wording is stronger than the page.

**What would resolve it.** Edit the four phrases.
