# Title: the comparison does not "isolate the one new decision": no comparator separates A1's sizing and ranking from a size-tuned frequency core

**Grade: DECISIVE for the stated reason the candidate deserves investigation (DPR-0005 section 5: "it makes the one new decision (the core rule) the only difference, so the comparison isolates it"); fixable by adding arms.**

**Objection.** HYP-0013's comparator set is P0, P1 with the same `F`, P3-vendor (vendor rule), and the same `F` with a listed grade. (1) P1-with-the-same-`F` differs from C-A only by the search interface: it isolates search, not A1. (2) P3-vendor differs from C-A in the size of the core (a vendor rule of thumb, "3-5", EXT-0009), in the ranking criterion and in the data the core is chosen on. A C-A win over P3-vendor therefore cannot be attributed to the break-even rule; it may be sizing alone, or ranking alone. (3) No comparator takes the core size from a dev-measured end-to-end optimum under the real billing convention. A1 already requires full-catalogue dev runs (for `p_hat`) and a search-path pilot (for `q_hat`), so a direct dev sweep over core size, with the same frequency ranking, needs no price model, no `r`, `w`, `T_bar`, `d_s`. If that tuned core matches C-A, A1 adds nothing; if A1 beats it, A1 is more than a heuristic. Either is a result, but only if the arm exists. Three effects are currently confounded: (a) ranking `p_hat` vs `p_hat/L_t`, (b) size from break-even vs fixed vs swept, (c) the recoverability extension (Step 2).

**Evidence.** DPR-0005 section 5 last paragraph and section 6.5 (arm list); HYP-0013 front matter (comparator list); DPR-0004 sections 3.1(3), 4.2 row A1; EXT-0009 l.31 ("Keep your 3-5 most frequently used tools non-deferred"; a rule of thumb, no stated derivation).

**What would resolve it.** (i) Add to the arms and to HYP-0013's falsifier: a frequency-ranked core with the same `|F|` as A1's; a frequency-ranked core whose `|F|` is chosen by a dev sweep on the measured criterion; (ii) reword DPR-0005 section 5 so that "isolates" is claimed only against those arms; (iii) state the prediction that tests A1 as a model: whether its `F` matches the dev-sweep optimum.

**Response (proposer).** [round 1 reply, verbatim excerpt] "CONCEDE: CH-0020 (D; 'isolates A1' false: P3-vendor differs in size/ranking/data; added P1f/P3f and P-sweep; A1 must not be dominated by P-sweep)." [rounds used: 1 of 2]
