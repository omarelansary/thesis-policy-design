# Title: V5-R's additions over the simplest rival DPR-0008 are fewer than stated, the regime switch is not new, and "recommended" rests on a requirement, not on evidence

**Objection.** DPR-0008, written without reading `04`, contains the same regime switch on the tool block, deferral with native search, append after the prefix, an optional static filter (D0(b)) and a Markdown summary. The regime switch is also a shipped feature: Claude Code loads MCP tools upfront while their definitions total under 10% of the window and defers otherwise (`03` row 43), and both blind instances derived a switch independently. `06` section 1 nevertheless marks S2 "New as a rule" and DPR-0007 "What is new" names "the per-deployment regime switch". What is new in DPR-0007 beyond DPR-0008 is S1 as a named stage, M2-M3 and H. For M2-M3 the evidence is NONE FOUND in prior art (`03` row 69), no measured hit rate, and a biased h* (CH-0075). The `04` section 4 table labels V5-R "(recommended)" while its header says nothing is selected, and ranks DPR-0008 with empty cells. The honest reading is that V5-R = DPR-0008 + one treatment (M2-M3) because REQ-U21-04 asks for the combination; that is legitimate but should be said, with DPR-0008 as the default arm and the null. The verdict "V4 substantially revised" is mostly driven by the new objective (DPR-0006, the human's REQ-U21-07), not by evidence about the parts.

**Evidence.** `design/proposals/DPR-0008.md` section 1 (rules 1-4), section 4 rule 2; `design/package-v5/03-reuse-map.md:43, :69`; `06-contribution-and-traceability.md` section 1 (S2 row); `04-design.md` section 1 point 4, section 4 table; DPR-0007 "What is new".

**What would resolve it.** Reword the "new" claims to: the break-even derivation for S2 (the vendor threshold is a window share, not a bill break-even) and M2-M3; present V5-R as DPR-0008 plus M2-M3 (plus S1/H only if separately justified); compare the vendor's 10% window rule with D-01's n* in tokens (about 20k tokens at a 200k window against 2.5k-18.5k tokens for n* = 10-74 at d = 250) to show what the derivation adds.
