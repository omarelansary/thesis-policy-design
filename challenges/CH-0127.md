# Title: PL-3 renews a seed "when the seeded tool is actually called", which is the rule its own cited source avoids and which `15` s4.2 shows is circular

**Objection.** (a) PL-3 says each seed entry "expires after a period without reinforcement, renewed when the seeded tool is actually called". `15` s4.5 and s5 report, correctly, that the cited source (Copilot, G20) resets expiry on an upvote and that "Simply retrieving a memory does not reset this period". PL-3 then adopts a use-based reset without saying it departs from the source it cites in its evidence column (G20 corrected). A call is the analogue of retrieval, not of an upvote.
(b) `15` s4.2 reports E22: a tool named in a context file was used about 1.6 times per instance against under 0.01 when not named, and `15` itself concludes "a seeded tool will be used". If naming a tool makes it get called, then "called" measures the seed, not the need; a seeded entry renews itself every session and never expires while it is offered. The record states the premise and then proposes a rule that the premise defeats.
(c) The signals the landscape does offer for "was this memory useful" are not used: scout G's G12 row (experience-following: errors compound; a later outcome is a free quality label for a stored entry) is unchecked and absent from `15`; D4 (checked, SUM-0059) shows the strict writer that beat add-all was a simulated oracle using ground truth. PL-3 names no usefulness signal other than the call.

**Evidence.** `evidence/literature-20261019/v5-ls-g08-github-agents-copilot-memory.txt` L137, L149, L155 (reset on upvote; retrieval does not reset); SUM-0060 G20; SUM-0063 E22 (L654-660 of v5-ls-e02, 1.6 versus 0.01; 2.5 versus 0.05 for repository tools); SUM-0059 D4 (L352-363 oracle evaluator); `inputs/scout-reports-landscape-20261028/G-staleness-security.md` row G12.

**What would resolve it.** Either (i) renew only on an independent signal (for example, a seeded-tool call whose result the task used, or a task accepted) and say so; or (ii) state that the renewal signal is an open choice, mark the use-based variant as the circular one, and add the arm "seed with no renewal / fixed expiry" to PL-7; and (iii) say in PL-3 that it departs from Copilot's reset rule.
