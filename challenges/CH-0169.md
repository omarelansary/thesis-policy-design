# Title: Completion check marks CC4 and CC5 more favourably than the evidence allows and the limitations list omits the main risks

**Objection.**
1. *CC4 "Partly".* CC4 says "for each shortlisted candidate, a search for independent criticism ... was made; material criticisms are checked against their source". For the benchmark that carries five experiments the record is: issues read by titles only (L171, "P"), no independent audit found (scout E32), no open-weight scores (scout B), and the scout's one claim about Epoch not covering AppWorld not found on the stored page (SUM-0077 L39). That is "not met" for AppWorld, not "partly" for a mixed set. For the multi-session candidates (ATRBench, VitaBench 2.0, Momento) the register says only "no independent criticism found", which is the same absence.
2. *CC5 "Yes".* CC5 requires "uncertainty" per experiment; P1 and P4 firsts are left open, which s10 notes ("two choices left open"). Fine. But s7 P2, P3 and E2E carry rank 1 without the conditions in CH-0159 and CH-0162, so "Yes" holds for form, not for content.
3. *Limitations list (L271) omits.* (a) concentration on one benchmark (CH-0158); (b) ceiling and judge noise on MCP-Atlas (CH-0162); (c) contamination (CH-0162); (d) the replay design and the keyless-subset definition (CH-0163); (e) that the independent ranking did not read the stored pages and used the same cards (DPR-0010 s0); (f) licence status of captured definitions (CH-0164); (g) clustering (CH-0161). It also lists AppWorld's "scenario structure" as unchecked when the stored paper states it (CH-0159), which reads as lack of access rather than lack of reading.
4. *CC7 "Yes ... none made".* The list in s9 is honest, but s4 revision 2 changes P3 H1, P1 H5 and E2E H5/H6 for ranking purposes: these are changes to the register's hard requirements, flagged as such; not changes to V5. Accepted. The statement in s9 item 3 that "nearly the same cannot be tested without a margin" is a new reading of REQ-U21-07, offered as a choice, which is acceptable.
5. *Status line.* L3 says "adversarial review of sections 7-10 pending" and s10 CC6 says "no adversarial review"; both will need updating with this review (RV-0028), including that the review found one blocking item.

**Evidence.** [F] register L3, L171, L259-271; scout E32; SUM-0077 L39; DPR-0010 s0. [I] that "Partly" understates the AppWorld gap.

**What would resolve it.** Re-grade CC4 per candidate (a column "criticism search: done / titles only / none"); add the omitted items to the limitations; update CC6 after adjudication.
