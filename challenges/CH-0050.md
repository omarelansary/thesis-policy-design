# Title: the cost-indistinguishable set S is stated ambiguously, is selected on the same data as feasibility, still grows as data shrinks, and epsilon is another tie rule

**Grade: SERIOUS for (1)-(4), MINOR for (5).** (02 section 6.)

**Objection.**
1. **Direction is ambiguous as written.** "Arms in F whose paired cost difference to every other arm in F is not separable from zero in the downward direction" can be read as "no arm is significantly cheaper than it" (the intent, from the "equivalently" clause) or, literally, "it is not significantly cheaper than any other", which would remove a clear unique winner and keep the dearest arms. Write it as: a is in S iff no b in F has an upper confidence bound of cost(b) - cost(a) below zero.
2. **Procedure and error rate unspecified.** "At the stated error rate" has no stated rate; `alpha` is listed as unset in the preface. The model-confidence-set literature is cited "not verified here". Pairwise screening of |F| arms needs a multiplicity rule distinct from the six-contrast Bonferroni of section 7, and the way the two error rates combine is not given.
3. **Selection on the same data (the question asked).** F is chosen by noninferiority tests on split B; S is then computed among F on split B. A coverage guarantee for a confidence set of best arms holds for a fixed candidate set, not a set chosen by a correlated test. Success and cost are correlated per task (failing trajectories can be short or run to the turn limit), so arms that pass the noninferiority test by favourable noise are not a random sample of cost differences. The test split (S6) re-estimates the chosen arm only, so S and the "within epsilon" statement remain post-selection quantities on split B. This is a standard post-selection concern [I, general statistical background; not from the stored evidence].
4. **The sample-size dependence is moved, not removed.** S contains every feasible arm when data are few and shrinks as data grow; that is honest uncertainty, but "the report names S, not a single winner" and the epsilon preference pick by the estimated minimum, which is biased low (winner's curse) and moves with n. The proposed sensitivity (subsampling the development set) reveals instability downwards (fewer tasks than collected) and cannot show what more data would return; nested subsamples are not independent replications. It reports the dependence; it does not fix it, and 03 section 1 row 2 says the rule "now" does the latter.
5. **Epsilon.** The one-standard-error rule's tolerance is the standard error, which shrinks with n (so it has the same sample-size dependence the rule was meant to avoid, with an adaptive tolerance); a fixed `epsilon` in tokens does not. They are not "equivalent in spirit". In option (a) the set S plays no role in the choice (the simplest within `epsilon` of the minimum), and `epsilon` is a free parameter that decides the outcome; it is unset and the lead leaves it to the human. That is permitted (a decision for the human), but the text calls it "reported as a preference, not equivalence" while the brief uses "stage kept" language.
6. **Where I looked for "not distinguishable" read as "equal" in v4 and found none** in the Figure/protocol text. The one place it recurs in disguise is the stage-inclusion rule (CH-0049) and the brief's "within noise" for the hierarchical router (CH-0055).

**Evidence.** 02 lines 84-93; preface line 3; no stored source involved.

**What would resolve it.** Rewrite the definition of S with the direction explicit and the error rates named; say whether S is computed on the same split as F; present the sensitivity as a description of the decision's variability, not a remedy; separate the free parameter from the rule.

**Response (lead).** ACCEPT: S defined directionally; post-selection caveat; sensitivity shows instability toward smaller samples only; epsilon described as a deliberate payment for simplicity, not the 1-SE rule. [rounds used: 1 of 2]

**Round 2 (challenger, 2026-10-19): CLOSED, minor residual.** Checked 02 section 6: "a is excluded from S if some other b in F has cost(a) - cost(b) with lower confidence bound above zero" is the intended direction and is coherent (a arm is excluded only if shown costlier than another feasible arm; the unique cheapest is never excluded). Post-selection and sensitivity statements are honest. Residual R7 (minor): "the stated family error rate" is unnamed (alpha is declared unset, which is acceptable) and "simplest" has no order (see R2). The ambiguity of S under the unset alpha is a human decision, not a defect.

**Outcome.** resolved (conceded) with minor residual R7.
