# Title: The design rests on beta and provider-specific features with no fallback for the user's actual route, and P0 cannot observe half of HYP-0020's falsifier

**Objection.** The mechanism that makes memory-informed offering possible without a cache break is `tool_addition` / `tool_removal`: beta (`inline-tools-2026-09-15`), "listed models only", the same page says mid-conversation system messages are not available on Claude Sonnet 5, and by-reference changes need `mid-conversation-tool-changes-2026-07-01` on some platforms (`L/v5-anthropic-midconv-sysmsg-20261022.md:18-20, :27`). OpenAI `allowed_tools` only restricts among declared tools (`L/v5-openai-prompt-caching-20261022.md:441`), so it works with an expose-all prefix, not with the deferred P0b prefix; OpenAI tool search is gpt-5.4 and later only (`03` row 42); context editing for H is beta; the Anthropic memory tool is used through the `beta` SDK namespace. The beta status is noted in one sentence (`04` section 8, DPR-0007 assumptions), but the dependence is wider (models, platforms, headers, H) and the design has no branch for the user's route: "an API free from my university and it offer bunch of different AI models" (REQ-U21-01). If that gateway does not pass beta headers, tool search, or cache fields, D-01 and D-02 do not apply: with no caching w = r = 1 and deferral wins at far smaller catalogues; M3 would have to fall back to injecting text. HYP-0020's falsifier includes "the API applies no cache discount", which cannot be seen in a usage record of a free API (tokens are shown, prices are not); only the fields can be read, not whether a discount applies. `04` section 5's one fallback ("a client search must keep the prefix and append") does not cover the case of no caching.

**Evidence.** `L/v5-anthropic-midconv-sysmsg-20261022.md:18, :20, :27`; `L/v5-openai-prompt-caching-20261022.md:441`; `03-reuse-map.md:29, :42`; `L/v5-anthropic-context-editing-20261022.md:31`; `L/v5-anthropic-memory-tool-20261022.md:294-320`; `hypotheses/HYP-0020.md` falsifier; `requirements/REGISTER.md` REQ-U21-01; `04-design.md` sections 5, 8.

**What would resolve it.** List per mechanism: model, platform, status (GA/beta), and what the policy does when it is missing (a table in `04`); add a no-cache branch to D-01; split HYP-0020 into "fields present" (observable in P0) and "discount applied" (only checkable by latency or a priced route), and say which one the bill depends on.
