# Title: the Copilot row overstates "memory as future work" and understates that Copilot already uses usage statistics to choose offered tools

**Objection.** 03 L53 and L69 say Copilot "names [memory-informed offering] as future work" and that "remembering previous tool usage is named as future work". EXT-0228 L71-L73 says: "A truly intelligent model shouldn't just react to queries; it should remember previous tool usage, infer intent from history, and plan multi-step actions over long sessions"; "Our next step is to explore how embeddings, memory, and reinforcement signals can combine to create context-aware agents that learn how to use tools, not just which ones to pick." This is a general aspiration about reasoning over time and learning to use tools. It does not name memory-informed choice of which tools to offer, and the last clause ("not just which ones to pick") points away from it. Meanwhile EXT-0228 L61 says the 13-tool core was chosen "Based on tool usage statistics and performance data": usage history already decides what is offered, aggregated over users, offline. So the V5 gap is per-user or per-role seeding at session start, not usage-informed offering as such. The map's and 02's framing ("core of REQ-U21-04 is OURS") is right only for the narrower gap; the wider statement can mislead a reader into thinking nothing usage-informed exists.
Two smaller points in the same row. The "2-5 points of resolution rate" (L59) is for the built-in toolset on benchmarks "including SWE-Lancer", with no sizes and no counts given; 04 section 4 K0 uses it as an accuracy risk for K0 in general. The coverage metric (94.5 / 87.5 / 69.0) is the vendor's offline "Tool Use Coverage", not task success.

**Evidence.** EXT-0228 L49-L53, L59-L61, L67-L73; 03 L53, L69; 04 L64.

**What would resolve it.** Re-word to "Copilot's core set is chosen from aggregate usage statistics; its next step mentions memory for agents that learn tool use; per-user memory-informed offering is not described". State the gap as per-user or per-role.
