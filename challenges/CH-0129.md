# Title: PL-5 pools user text across users (the cross-user write path PL-8 warns about), the triage dismissed the governance material that bears on it, and the evidence for PL-8's weight omits the contrary replication

**Objection.** (a) PL-8 says per-role pooled seeding "lets one user's sessions shape another's seeds and is a cross-user write path". PL-5 proposes that "W's logged question-to-tool pairs, pooled over users, enrich the D ranker's index offline". That pools user-authored text across users into a store every user's ranker reads. Keeping it out of the cached prefix answers the cache question, not the poisoning one. The record treats the two proposals as independent; they share the mechanism.
(b) `15` s1 dismisses "ACLs, GDPR, backups, migration" as infrastructure "for memory as a shared service; V5's memory is a plain file". PL-5 and the per-role option of PL-8 are exactly a shared pooled store. Scout G's G22 (OWASP agentic Top 10, ASI06 mitigations recurring across secondary sources: segment memory by user, task or tenant, provenance with decay, rollback) is stored (`v5-ls-g23-owasp-download-52117.txt`) but not read; `15` s7 says so. Retention and consent for pooled university-user text is not discussed anywhere in `15`.
(c) PL-5's evidence is thin and partly flagged by the stewards: Tool2Vec = Z5 in `14` (SUM-0053 "row headers not read"); D14 is a lead (unchecked) and the scout notes ToolBank queries are LLM-synthetic, with cold start for new tools not discussed; A21 is used for "usage statistics aggregated over users", but SUM-0063 A21 says the page states only "tool usage statistics and performance data" and "source population not stated". The word "pooled" is therefore the lead's inference for A21.
(d) PL-8's weight rests on MINJA at abstract level (G3, a lead, no success rates). Scout G's G4 (a replication: "realistic conditions with pre-existing legitimate memories dramatically reduce attack effectiveness") and G7 ("it is difficult to make an agent overwrite its own memory files using untrusted external content") are unchecked, absent from `15`, and both cut the other way. The direction of the net evidence on pooled-write risk is not shown by `15`.

**Evidence.** `15` s6 PL-5, PL-8; `15` s1 triage table last-but-two row; `inputs/scout-reports-landscape-20261028/G-staleness-security.md` rows G3, G4, G7, G22; SUM-0063 A21; SUM-0053 (cited in `14`); D-tool-memory-research.md row D14.

**What would resolve it.** Mark PL-5 as sharing PL-8's risk; add a one-line governance note (who may read the pool; retention; whether question text or only tool names are logged); read or drop G22; check G3, G4, G7 or state that PL-8's weight is unmeasured; reword A21 to "usage statistics (population not stated)".
