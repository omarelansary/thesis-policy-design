# Title: stored sources that favour the opposite conclusion are missing from the reuse map

**Objection.** Three stored items that both blind outputs or the stored file set contain, and that bear against memory-informed offering or against deferral as a default, do not appear in the map.
1. `L/lit-memskill-2609.16669.txt` L23-L35 (abstract): a memory carrier built as a Skill with resident, on-demand and reference levels (L0, L1, L2, progressive disclosure); at the priced operating point the first-turn tokens were tied at k = 1 (1,313 against 1,365), and session totals differed by only 1.18x. Both blind outputs cite it as evidence that memory overhead can cancel savings (blind A L101, blind B L100). It is also a stored example of a staged, progressive-disclosure carrier. Absent from slots 4 and 5. Weak evidence (one deployed system, small comparisons), but it is the only stored measurement of what a memory carrier costs per turn.
2. `L/web-agentpatterns-dynamic-tool-fetching.txt` L97-L109: deferred loading "gives no benefit" below 10 tools, when all tools are needed every request, and "Tool search accuracy is low: poor search hits miss tools, and that hurts task completion more than cache breaks cost"; "Stable tool sets are the right default for multi-turn agents." A practitioner page, not evidence of effect, but it is a stored statement for the K0 or V4-unchanged side, and blind A cites it (blind A L86).
3. Anthropic Agent Skills (progressive disclosure of skill metadata, then body, then references) is the vendor's own shipped staged-exposure design and is asked for in the scout prompt (`scout-prompts-20261022.md` L32). The search log has no query for it and the map no row.
The map's slot-4 "closest shipped analogue" is therefore only Copilot, plus LangChain's static core.

**Evidence.** Files and lines above; 03 has no match for "memskill", "agentpatterns" or "Skills" (grep of the package: only blind outputs and the scout prompt match).

**What would resolve it.** Add rows (or an explicit "read and set aside, because ...") for items 1 and 2; run or log a search for item 3. The map should say which stored sources point toward "expose all with caching" or "no memory", not only those that support the V5-R parts.
