# Title: "The gap stands" drops the scouts' own unread near items and several nearest items, and the four-part conjunction is easy to satisfy

**Objection.** (a) The statement is a conjunction of four parts (per user or role, tool definitions seeded, large catalogue, session start with the bill measured). Each part exists somewhere in the record; only the conjunction is absent. `15` says "not found in the places searched", which is correct, but then "Reading: the gap **stands**" and s7 builds "unchanged" on it.
(b) Scout D's own section 4 lists items it did not read: PrefTool (EMNLP 2026 Findings, personalised tool retrieval, "type-aware history modeling"; abstract page only), DTDR (execution-history-conditioned retrieval; second-hand only), 2606.04703 and 2604.16968. D wrote "'Not found' here means not read". `15` s4.4 carries none of them; "Not found, in any of the seven searches" reads as if they were searched and excluded. Scout D's per-user-tool-history queries were five (listed in its section 4).
(c) Nearest items in the scout reports that `15` omits: G17 (Claude Code persists a per-user discovery cache of tool lists across sessions: stored page `v5-ls-g11-claude-en-mcp.txt` L277-278 says it is "off by default unless a gradual rollout has enabled it" and "Before v2.1.238, the cache was on by default", so a shipped persisted tool list was demoted, which also bears on s4.8); D15 AutoTool (history-derived priors save model calls; small environments); E13 ATRBench (cross-session, 74 tools, measured cache-hit rates; already in `03` as a possible harness); E12 Mem2ActBench (400 memory-dependent tool-use tasks; per scout E, tool accuracy roughly 92-97% for most systems, i.e. near ceiling, and plain RAG within about 0.6 F1 of the best memory system; V5 `04` L79 already cites it).
(d) Balance of the nearest-work list: `15` lists the nearest items "each lacking a conjunct" but not what they say about whether seeding is needed. E12 (selection near ceiling at small catalogue) and D13 ToolSpectrum ("The more factors considered in personalization, the worse the performance", stored `v5-ls-d24-arxiv-pdf-2505.13176.txt` L767-768; tool-selection accuracy) are the two stored items that bear on M2's premise and neither is in `15`.
(e) The statement "matches `03` section 5 and widens its search base" is a search-effort claim; no query list or hit count for the seven scouts is stored (s7 admits result lists are not stored).

**Evidence.** `inputs/scout-reports-landscape-20261028/D-tool-memory-research.md` s4 (lines 73-84); `.../E-evaluation.md` E12, E13; `.../G-staleness-security.md` G17; stored pages as cited; `15` s4.4, s7.

**What would resolve it.** Rewrite s4.4's first bullet as "not found in the pages read; not read: PrefTool, DTDR, ...", list G17, D15, E12, E13 and D13 with what each says, and either read PrefTool and DTDR or say they are the first things a reviewer should read. No change to V5 is needed; this is about how strongly the absence is worded.
