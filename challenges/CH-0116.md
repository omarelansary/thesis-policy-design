# Title: "No checked source contradicts keeping them" has no stated test, and the stored text contains adverse results that the record softens or omits

**Objection.** `14` s4 says nothing in V5-R10, V5-R11 or the loop changes and "No checked source contradicts keeping them". "Contradicts" is not defined; the check compared scout claims with pages, so a contradiction could only appear if a scout reported one. Several stored pages carry results that bear against the ideas as written, and `14` either omits or weakens them:
(a) V5-R10 (short entries first, full schema on request). The paper behind X9 (2511.03728) states: "If the required tool is not selected in the first stage, its full schema is unavailable during argument generation, making subsequent recovery or pivoting more difficult. We therefore view Memory-Efficient as the primary interaction-memory configuration, while Combined represents a more aggressive deployment operating point when the static tool bank itself is also constrained" (L723-728). The record says only that precision rose and recall fell. The authors' own preference for the variant without JIT loading is the nearest stored statement on the short-first idea, and it is not mentioned. The agent there is Qwen3 1.7B and a Qwen3.5 user simulator (L257-265), so "small models" is right, but the transfer to the thesis's models is [U].
(b) The only vendor benchmark of dynamic toolsets (X18) is cited for its costs (2-3x tool calls, about 50% time). The same page says "the dramatic reduction in token usage results in overall cost savings" and expects execution time to approach static for long runs (`v5-xp-speakeasy-dynamic-toolsets.txt` L87, L95-97). Both halves are the vendor's own, in a product it sells; `14` gives one half.
(c) EX-4: Tool-DE reports rerankers on the original, non-expanded documents at -0.56, +0.27, +0.50 N@10 and on expanded documents at +0.37, +0.62, +1.20, with Tool-Rank-4B +4.21 (`v5-xp-arxiv-2510.22670.txt` L853-858), and attributes the difference to under-informative documents, so EX-4 and BR-6 are coupled. `14` treats them as separate measured items.
(d) The "keep" outcome is built in by the structure: the proposals in s4 are all additions (mark a number as unsourced, add measured items), none is a removal or a downgrade of a rule.
The accurate sentence is "no stored page falsifies the ideas; several qualify them, and the evidence for fixed levels L0-L3 is absent".

**Evidence.** As cited in (a)-(c). `14` s3 V5-R10 bullet 2; s4.

**What would resolve it.** Define "contradicts" (for instance: a stored result in which the idea's mechanism lowers accuracy or raises cost on a comparable setting) and list the stored items that meet it (X9 recall loss, Pydantic cache break on Chat Completions, ToolRet negative reranking, ToolEx oracle below retrieved set), or reword s4. Add the authors' preference in (a) and the vendor's offsetting statement in (b).
