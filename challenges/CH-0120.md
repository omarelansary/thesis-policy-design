# Title: The bill-term paragraph rests on a Speakeasy table whose token columns do not reconcile, from one preliminary run, and the conclusion "savings are not monotone" is drawn from two points

**Objection.** `14` states: "at 40 tools the semantic arm used 22,600 tokens against 1,300 static on a complex task, and cost $0.065 against $0.146, so savings are not monotone in catalogue size". The stored table (`v5-xp-speakeasy-100x.txt` L74-90) has columns "Initial Tokens, Simple Task Tokens, Simple Task Cost, Complex Task Tokens, Complex Task Cost".
(a) The token columns cannot be total input: 40 tools static has Initial Tokens 43,300 and "Complex Task Tokens" 1,300 at $0.146; 100 tools static has Initial 128,900 and Complex 1,300 at $0.155 (L76, L80). Identical 1,300 for a catalogue three times larger, and 1,300 tokens costing $0.146 against 22,600 tokens costing $0.065, show that "Task Tokens" counts something other than what is billed (the page does not say what; cached or initial context is the obvious candidate [S]). Juxtaposing 22,600 against 1,300 therefore misleads about the bill term, which is the one thing this paragraph is for. SUM-0055 states it did not read the column headings and that the interpretation is the scout's.
(b) "Not monotone" rests on complex-task costs $0.065, $0.134, $0.126, $0.160 for the semantic arm (L78, L82, L86, L90) from a single run per cell ("preliminary performance testing", L67), one model (Claude Code, Sonnet 4), no variance, and a static arm that does not run beyond 100 tools (L92). Two static points (40, 100) cannot show a trend in savings. The vendor's own reading is the opposite ("dynamic toolsets become exponentially more efficient", L112).
(c) The vendor is the seller of the product measured. `14` calls it "Speakeasy reports" without that label in this paragraph (it does say "one vendor benchmark" under V5-R10).
(d) Related: the X18 page's own offsetting statements (cost savings; execution time expected to approach static in long runs, `v5-xp-speakeasy-dynamic-toolsets.txt` L87, L95-97) are not given next to the 2-3x and 50% figures (see CH-0116 b).

**Evidence.** As cited; SUM-0055 Z21 note; SUM-0052 X18 row.

**What would resolve it.** State that the token columns are undefined on the page and not comparable with the cost columns, drop the 22,600 against 1,300 juxtaposition or label it as unreconciled, and replace "savings are not monotone" with "two static points on one preliminary run show smaller dollar savings at 100 than at 40 tools; no trend can be claimed". Keep "no checked source prices the extra request, the appended definitions and the cache effect together", which I could not break.
