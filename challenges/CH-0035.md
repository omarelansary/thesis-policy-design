# Title: the token form of A1 omits the extra model call that every discovery causes, and leaves d_s ambiguous

**Grade: DECISIVE for the token form of correction 3 (design/package-v3/01-errata-AUTH-005.md section 3, last paragraph). It does not touch the counterexample.**

**Objection.**
1. **Missing term.** Under the stated estimand (sum over turns of the whole prompt; "extra turns count", errata section 0) a discovery adds one model call: turn j emits the search, turn j+1 receives the result and emits the tool call, whereas under expose-all turn j makes the tool call directly. That extra call reads the *entire* context (system prompt, core, scope statement, search schema, history, the search exchange). The errata's `disc_t = p_t (1 - q_t) tau (d_s + L_t + (kappa-1) L_D)` contains only the content that persists (the exchange and the appended definitions, re-read tau times). It has no term for the prompt re-read by the extra call. In a long trajectory that prompt (history plus tool block) is typically much larger than `d_s + L_t`. [I; illustration, not data: context 20,000 tokens at discovery, `d_s` 300, `L_t` 200, `kappa` 5, `L_D` 200, `tau` 5 gives the errata's term 5 x (300 + 200 + 800) = 6,500, the omitted call is about 20,000, i.e. the formula undercounts discovery cost by a factor of about four.] Consequence: `s_t = keep_t - disc_t` is overstated for every deferred tool, so Step 1 and the incremental index defer too much, and the common deferral overhead is not the only missing common cost.
2. **Either d_s must be redefined or tau misused.** If `d_s` is meant to include the extra call's input, it must contain the whole context and must **not** be multiplied by `tau` (the context is read once by that call, not re-read `tau` times). If `d_s` is only the exchange tokens, the extra call is missing. As written ("the tokens of one search exchange", multiplied by `tau`) the formula is wrong in one of the two ways.
3. **Possible double count.** If the search result returns the definitions as tool-result text *and* the system then also appends them to the tool block, `L_t + (kappa-1) L_D` is counted twice (once inside the exchange, once as appended). The errata does not say that `d_s` excludes the returned definitions. Vendor deferral expands one `tool_reference` inline (EXT-0009 l.37), i.e. one copy; a system-appended design may have two.
4. **`tau` is common to all tools but is not.** A tool needed late in a trajectory has small `tau`; a tool needed early large. Using one mean `tau` per tool ignores that `tau` is conditional on when `t` is needed (the errata notes `T_bar` depends on the surface, not this).
5. **Unreached cases are not "only failures".** When `t` is needed but not reached, the model still issues searches (up to `B_s`), each costing an extra call and exchange tokens inside `C_tok`. Excluding them biases the index toward deferring tools with high `q_t`.
6. **"Common overhead shared by all deferral designs" is not shared with expose-all.** The test "defer at all" needs `sum_{t in D} s_t > (L_S + sigma) T_bar` (plus search-interface cost); the errata does not state it, so the knapsack as stated can return a nonempty deferred set that is worse than expose-all.

**Evidence.** Errata section 0 (estimand) and section 3 (token form), read in full. EXT-0009 l.25-37 (vendor: deferred definitions are not placed in the context window; a `tool_reference` is expanded inline when discovered; the prefix is untouched). I did not check the formula against any implementation or measurement (none exists).

**What would resolve it.** Add the term `p_t (1 - q_t) * P_j` (prompt tokens at the discovery turn, to be estimated from dev trajectories) to `disc_t`; define `d_s` as exchange tokens *excluding* returned definitions, or merge; state the defer-at-all inequality; add search costs of unreached cases. A measurement of per-discovery token increment on any vehicle would give the magnitude (not authorised). **Note for the lead:** this is checkable by the lead on paper against a hand-built three-turn trajectory.

**Response (lead, round 2).** Revised 01 section 3: `disc_t = p_t(1-q_t)[I_disc + tau A_t] + phi_t`, `A_t = d_s + L_t + (kappa-1) L_D` with `d_s` excluding returned definitions, `I_disc` = input of the call that emits the search excluding appended content, `tau` = calls after it, `phi_t` for failed searches, and the defer-at-all test `sum s_t > Omega = (L_S + sigma) T_bar`. [rounds used: 1 of 2]

**Round 2 (challenger): WITHDRAW as decisive; resolved, two minor residuals.** Hand check, three-call trajectory (call 1 emits the search, call 2 the tool call, call 3 the answer; expose-all baseline has two calls, `T_bar = 2`, call 1 the tool call, call 2 the answer). Let P be the prompt without `t` at call 1. Deferred total = P + (P + A) + (P + A + h) where h is the history common to both designs (tool call and result); baseline = (P + L_t) + (P + L_t + h). Difference = P + 2A - 2L_t = `I_disc + tau A_t - keep_t` with `tau = 2`, `keep_t = 2 L_t`. So the extra call is counted exactly once (as `I_disc`); the search exchange is counted once, inside `A_t`, re-read `tau` times (its output tokens enter later inputs); the returned definitions are counted once; no double count. Interface tokens: the deferred run has three calls, `Omega` covers `T_bar = 2`, the third is inside `I_disc` (which includes the interface), so no double count there either. A prior discovery's appended content is re-read by a later discovery's extra call through that earlier tool's `tau`, so `I_disc` excluding appended content is consistent. Residuals: (a) searches in trajectories that need no deferred tool (false initiations, each an extra call plus exchange) are not in any term; `phi_t` covers only needed-but-unreached sessions; (b) `I_disc` and `tau` must be conditional on `t` being the needed tool (a late-needed tool has a large `I_disc` and small `tau`); the text says "expected" without the conditioning; `phi_t` also double counts a failed search shared by two missed tools in one session. Both minor.

**Outcome.** conceded (token form corrected; residuals (a), (b) minor, answerable now).
