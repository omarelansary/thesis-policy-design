# Title: Saturation evidence does not support "more likely a real gap"; round 3 itself found new neighbouring work

**Grade: SERIOUS for the thesis-case sentence (`05` section 2 item 5), MINOR for section 3 itself, which hedges.**

**Objection.**
1. "Same papers recur" measures the search engine's ranking, not coverage of the literature. Recurrence across queries from one vocabulary shows the queries are alike [I]. `05` section 3 admits the sample is search-engine driven; section 2 item 5 still says "three specific, citable gaps", which reads as established.
2. Round 3 was not a null round on topic B: its searches produced nine papers on false-positive tool calling and tool overuse (The Reasoning Trap, Tool-Overuse Illusion, ToolBeHonest, SMART, SMARTCAL, Adapt-LLM, adaptive retrieval, outcome-driven search, ToolSandbox), none of which appears in SUM-0005 passes 1-3 [I; I did not re-read SUM-0005 for this]. `05` also says "18 searches" in total while TASK.md says round 3 added 10 to the AUTH-011 searches; the count that "the same papers recur" across is unclear. A stopping rule of "same papers recur" is contradicted by that yield for the sub-question where new queries were used. The queries that found nothing new (vendor tool search, appended-definition cache) were reworded variants, not different vocabulary; `05` section 5 lists the different-vocabulary pass as not done.
3. The gap claims are conjunctions: "uninstructed + search channel + large hidden catalogue" is unmeasured because each paper differs in at least one element. A conjunction of absent elements is the weakest kind of gap evidence: some study may have the three together without the words used in the queries (e.g. a tool-search ablation inside an MCP benchmark paper).
4. Topic A: the stored text of CacheRouter (EXT-0112:177-179, 185-186) reports a cold-start A/B "confirms the prefix stays stable across gateway restarts and tool evolution"; this is a (weak, self-reported) observation on changed tool sets and a provider cache field; "no measurement of the cache behaviour of definitions changed mid-session" should say "no independent, billed, baseline-controlled measurement".

**Evidence.** `05` sections 2-5; EXT-0112:171-195.

**What would resolve it.** Wording: replace "more likely" with "not excluded by this sample"; list what a differently worded pass would test (queries in the review). Needs a bounded different-vocabulary search to say more.
