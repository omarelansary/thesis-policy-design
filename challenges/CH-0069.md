# Title: The Reasoning Trap "no-tool-available" rate is not a rate of calling a tool when none fits

**Grade: SERIOUS.**

**Objection.** `05` section 3, section 4 and the `01` row say "hallucinated / invented a tool when none fits" with rates 1.0-96.3%. The stored text defines something narrower and different:
1. The NTA queries are "Explicit Invocation Queries where the user directly names the required tool (e.g., 'Please use the get_restaurant_address tool to find...')" and "the system prompt contains no tools" (arxiv-2510.22977.txt:1241-1248). The user instructs the call. Section 3.1 of the same paper describes the query differently (a need such as the current time, :216-222). Text and appendix disagree; the appendix is the operative one for the data.
2. The judge counts a plain answer as a hallucination: "If the LLM directly answer user query, it should be considered a hallucination" (:1519-1521), as well as claiming a tool exists or using it (:1511-1518). So the rate is "did not refuse or say the tool is missing", not "made a tool call". The judge is DeepSeek-R1 (:1478), which is also an evaluated model (:1758); the human check is "a subset", no agreement figure (:1482-1485).
3. The prompt is "You are a helpful assistant." (:1286) with the closing instruction "You must not use any tools that are not explicitly provided" appearing only in the DT prompt region (:1467-1468) [I; which prompt that sentence belongs to was not checked].
4. DT (the "one irrelevant tool provided" rate, 15.5% to 100%) counts "attempts to use the distractor tool or hallucinates a more appropriate one" (:235-237): two behaviours in one number.

So these rates measure compliance with an explicit instruction to use a missing tool (NTA) and use-or-invent with a distractor (DT). Neither is the spontaneous false-positive call of a model that decides by itself whether a tool is needed. The `01` headline "Models call tools when none fits" overstates.

**Evidence.** arxiv-2510.22977.txt lines cited above; table values verified: Table 1 (:497-528) and Table 5 (:1736-1767): Kimi-K2 instruct 1.0 / DT 15.5; Qwen3-8B think-off 4.1; DeepSeek-V3 10.8; DeepSeek-R1 17.6; Qwen2.5-7B-inst 34.8; Llama3.1-8B-inst 62.5; Llama3.1-8B R1-distill 96.3 (all as in `05`).

**What would resolve it.** Edit: state that NTA queries name the tool and that direct answers count; drop "invented a tool when none fits" as the label; keep the numbers. Needs-data question for the pilot: the share of tasks where the model volunteers a call without being asked.
