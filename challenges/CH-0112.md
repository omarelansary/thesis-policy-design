# Title: the 27 Oct "not found" claims have no stored query log, and "no published break-even" overlooks two stored sources that print a threshold or a break-even

**Objection.** (a) `13` s1 and s4 state "No published break-even for client-side tool discovery or for memory seeding was found", "no source explains gpt-oss-120b" (s3: "no stored source explains it") and "X time-based charges: No counterpart found". The only search log is `search-log-20261022.md`, dated 22 Oct, which says of itself that its scout queries "were not audited ... Section 1 therefore supports no 'not found' on its own" (L20). The scout prompts file (27 Oct) asks the scouts to report "the queries run" but the replies are not stored in the repository, so the reader cannot tell what was searched. `13` s3 scopes its own claim ("no stored source") correctly; s1 bullet 4 and s4 do not say where the search was made.
(b) Two stored sources are closer to the absent item than the text admits. `v5-anthropic-tool-search-20261022.md` (FND-0044 B20, L830-831) gives a published rule: tool search for "10 or more tools" or "more than 10k tokens"; it is a vendor threshold, not a derived break-even, but it sits at the same n as the lead's D = 1, T = 10 result (n* 11-14) and is a possible external cross-check that `13` s4 never mentions. `v5-lit-keepcachewarm-2607.19214.txt` prints a break-even for a related decision (keepalive vs re-write, I_max = tau (w/r - 1)); `13` s4 cites it as a missing term, not as the one printed break-even in the stored set.
(c) Wording "none found" without the stored-set scope can be read as absence in the literature. The human asked for scientific citations; this item is the one place where the absence is the finding.

**Evidence.** `inputs/search-log-20261022.md` L20 and L5-12 (22 Oct queries only); `inputs/scout-prompts-literature-20261027.md` L13; FND-0044 B20, B24; `13` s1 bullet 4, s4 last paragraph.

**What would resolve it.** Store each scout's list of queries (as the 22 Oct log does) or state that they are not stored; word the claim as "not found in the stored set or in the scouts' reported queries (not stored)"; add the Anthropic 10-tools / 10k-token rule and the keepalive break-even to s4 as the nearest published thresholds, with their limits.
