# PWD-004 P1-022 ToolRet static retrieval baseline
- Status: done (development matrix once, partition-level second matrix once).
- Dates: determinism preflights and development result 2026-07-31; second-partition result 2026-08-01.
- Reruns: none needed for models (no LLM). Retrieval is BM25.
- Purpose: a policy-only static retrieval gate: does deterministic BM25 over raw tool documentation differ from a request-independent random baseline at small budgets (T-070 to T-073).
- Input
  - Tasks: ToolRet queries: 7,961 query rows, partitioned duplicate-safe into 6,376 development and 1,585 reserved rows (reserved partition of this ToolRet study only, unrelated to MCP-Atlas 71+18). Gold: ToolRet qrels (relevant tool documents per query), used only to score.
  - Tools: 44,453 native tool-documentation documents (ToolRet release, hash-pinned). Not MCP schemas. Definition size: UTF-8 byte reduction only.
  - Models: none (no LLM, no embedder).
  - Offering: a fixed top-B subset of the catalogue per query, B in {5,10,20}.
  - Memory: none. Sessions: single query.
- Arms: full exposure; ten fixed global random samples at each budget; BM25 at each budget with two request profiles (query only; instruction plus query).
- Measures: query-macro qrel recall with paired bootstrap against same-budget random; document-byte proxy. No token counts.
- Sample: each matrix ran once on each partition; two-pass label-free selection preflight; ten random seeds.
- Output: `PUBX/p1_022_toolret_static_baseline_result.md`; private safe manifests on branch `p1-022-toolret-heldout-report` of thesis-private; `PRIV/p1_022_*`; `thesis-private/.../scripts/p1_022_*.py`.
