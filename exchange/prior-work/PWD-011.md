# PWD-011 FitText and Re-Invoke on MCP-Atlas (LLM-generated queries and document expansion; exploratory)
- Status: done as exploratory, unregistered runs. Records mark several runs as confounded or unresolved (see Not done).
- Dates: Re-Invoke 2026-09-09; FitText 2026-09-10 (Qwen), 2026-09-11 (Flash variant), neutral-prompt variant 2026-09-10; Re-Invoke on E0's embedder: addendum 2026-09-12.
- Reruns: none. Generators `Qwen/Qwen3.8-27B` (FitText) and `meta-llama/Llama-3.3-70B-Instruct` (Re-Invoke) are both listed as served now (live state 2026-10-29 12:05 UTC), so rule 5 does not call for a rerun on model grounds.
- Purpose: whether LLM-generated queries (FitText: a generated description of the tool needed) or generated document expansions (Re-Invoke: synthetic usage requests appended to each tool document) retrieve the needed tool better than the prompt or the accumulated history (PRIV/fittext_result_2026-09-10.md; `thesis-main/scripts/active_registry/benchmark_reinvoke.py`).
- Input
  - Tasks: MCP-Atlas development tasks. FitText static mode: the 71 tasks scored against the reference tool set. FitText iterative mode: 204 cycles taken from replayed `full_exposure` runs, scored against the tool actually called next. A ToolRet gorilla-huggingface static run also exists. Re-Invoke: 126 document expansions plus 71 query expansions.
  - Tools: the 126-tool catalogue.
  - Models: FitText generator `Qwen/Qwen3.8-27B`, embedder `Qwen3-Embedding-4B`; a Flash generator variant (name in `PO/fittext_flash_2026-09-11/`, not read). Re-Invoke: generator Llama-3.3-70B, N = 5 requests per tool, embedders MiniLM and Qwen3-Embedding-4B.
  - Offering: retrieval only, no live exposure.
  - Memory: iterative mode builds the probe from the conversation up to cycle k (history); no stored memory.
  - Sessions: single task, multi-cycle (replayed).
- Arms: FitText: task-text baseline vs generated probe (static); the thesis's own effective query (prompt + prior tool names + recent assistant text) vs generated probe (iterative). Re-Invoke: `doc`, `query`, `both` modes.
- Measures: Recall@5/10, Completeness@10, hit@5/10, MRR, median rank of the found tool. No tokens.
- Sample: 275 FitText generations (zero empty per the record); Re-Invoke about 197 generations; one run per arm; unpaired z reported although the arms score the same events.
- Output: `PO/fittext_2026-09-10/` (events, caches, analysis.md), `PO/fittext_flash_2026-09-11/`, `PO/fittext_neutral_prompt_2026-09-10/`, `PO/reinvoke_2026-09-09/`, `PO/tool_finding_matrix_2026-09-10/config.json`; `PRIV/fittext_result_2026-09-10.md`.
