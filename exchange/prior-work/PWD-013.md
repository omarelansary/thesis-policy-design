- Purpose: "For the minority of P1-029 tasks where `full_exposure` beat `oracle_gold`, did specific non-gold tools causally contribute, or were they merely correlated with successful trajectories?" (design section 0).
- Input
  - Tasks: 7 development tasks chosen from P1-029 data by a frozen, P1-029-informed selection rule (Rule B), i.e. selected after seeing P1-029 outcomes. Gold: the benchmark reference set; a "candidate set" of one to three non-gold tools was derived per task from P1-029 trajectories.
  - Tools: the 126-tool catalogue, byte-identical tool objects across arms.
  - Models: as PWD-012 (GLM-5.3-Flash, judge Llama-3.3-70B at 0.75, max_turns 50). Why GLM-5.3-Flash and not GLM-5.3: no scientific reason is recorded. The pre-run audit says the task model 'was selected by an HTTP 200' (`PRIV/p1_029_pre_run_audit_2026-09-15.md` item 8); on 2026-09-15 `GLM-5.3` returned HTTP 500 and `GLM-5.3-Flash` HTTP 200 (`PRIV/task_model_withdrawn_again_2026-09-15.md`). An earlier GLM, `GLM-5.2-FP8`, had been rejected for too few completions (`PRIV/p1_026_task_model_selection_failure_analysis_2026-08-27.md`). A live probe on 2026-10-29 shows both `GLM-5.3` and `GLM-5.3-Flash` answering HTTP 200; `GLM-5.3` has not been run on this task.
  - Offering: fixed tool set per arm.
  - Memory: none. Sessions: single task.
- Arms: `gold_only`; `gold_plus_candidate`; `full_minus_candidate`; `full_exposure`.
- Measures: task score; policy-zero rate contrast; per-task exact test; call-level census of the trajectories (as PWD-012 plus calls and failures per tool).
- Sample: 7 tasks x 4 arms x 5 repeats = 140 runs (5 repeats, not 3, because 3 produced boundary ties); arms interleaved.
