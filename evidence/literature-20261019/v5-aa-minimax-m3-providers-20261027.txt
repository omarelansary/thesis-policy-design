MiniMax-M3 is available through 12 API providers, each offering different performance characteristics and pricing. Below is a comparison of the key metrics across providers.
For output speed, the top providers are Nebius (FP8) (361.6 t/s), CoreWeave (NVFP4) (310.7 t/s), and SambaNova (199.5 t/s). Speed varies significantly across providers, with a 1366% difference between the fastest and slowest.
For latency, Nebius (FP8) (6.98s), CoreWeave (NVFP4) (7.63s), and Fireworks (10.93s) offer the lowest time to first answer token.
For pricing, CoreWeave (NVFP4) (0.18), GMI (0.18), and DeepInfra (0.21) offer the lowest blended prices per 1M tokens. Prices vary up to 4.4x across providers.
Nebius (FP8) offers the best performance with both the highest speed and lowest latency. For cost optimization, CoreWeave (NVFP4) provides the most competitive pricing.

What Cache Hit Rate Shows

The share of cacheable input tokens served from the provider's prompt cache, measured during multi-turn agentic coding sessions. We regularly measure each endpoint and report a representative rate based on recent measurements. Higher values mean more of the input is billed at the cheaper cache-hit price, where the provider offers one, which lowers the effective cost of agentic workloads. For further details, see our methodology page.

Frequently Asked Questions
Common questions about MiniMax-M3 providers

Where can I access MiniMax-M3?

MiniMax-M3 is available through 12 API providers: Parasail (MXFP8), CoreWeave (NVFP4), Together AI, Novita, Modular, Nebius (FP8), SiliconFlow (FP8), MiniMax, DeepInfra, GMI, SambaNova, and Fireworks. Each provider offers different performance characteristics and pricing.

How many API providers offer MiniMax-M3?

MiniMax-M3 is currently available through 12 API providers that we benchmark and track.

Which provider is fastest for MiniMax-M3?

The fastest providers for MiniMax-M3 by output speed are Nebius (FP8) (361.6 t/s), CoreWeave (NVFP4) (310.7 t/s), and SambaNova (199.5 t/s). Output speed measures how quickly tokens are generated after the model starts responding.

Which provider has the lowest latency for MiniMax-M3?

The providers with the lowest time to first answer token for MiniMax-M3 are Nebius (FP8) (6.98s), CoreWeave (NVFP4) (7.63s), and Fireworks (10.93s). Lower latency means faster initial response time.

Which provider is cheapest for MiniMax-M3?

The most affordable providers for MiniMax-M3 by blended price are CoreWeave (NVFP4) ($0.18 per 1M tokens), GMI ($0.18 per 1M tokens), and DeepInfra ($0.21 per 1M tokens). Blended price uses a 7:2:1 cache hit/input/output token ratio.

Which provider has the lowest input price for MiniMax-M3?

The providers with the lowest input token pricing for MiniMax-M3 are CoreWeave (NVFP4) ($0.23 per 1M input tokens), GMI ($0.24 per 1M input tokens), and DeepInfra ($0.28 per 1M input tokens).

Which provider has the lowest output price for MiniMax-M3?

The providers with the lowest output token pricing for MiniMax-M3 are CoreWeave (NVFP4) ($0.96 per 1M output tokens), GMI ($0.96 per 1M output tokens), and DeepInfra ($1.10 per 1M output tokens).

How much do prices vary across MiniMax-M3 providers?

Prices for MiniMax-M3 vary up to 4.4x across providers. The most affordable is CoreWeave (NVFP4) at $0.18 per 1M tokens, while SambaNova charges $0.78 per 1M tokens.

How much does speed vary across MiniMax-M3 providers?

Output speed for MiniMax-M3 varies significantly across providers. Nebius (FP8) is the fastest at 361.6 t/s, which is 14.7x faster than DeepInfra at 24.7 t/s.

Which MiniMax-M3 providers support JSON mode?

All 12 providers of MiniMax-M3 support JSON mode for structured output.

Which MiniMax-M3 providers support function calling?

Which is the best provider for MiniMax-M3?

For MiniMax-M3, Nebius (FP8) offers the best performance with highest speed and lowest latency. For cost optimization, CoreWeave (NVFP4) provides the most competitive pricing.

How do I choose a provider for MiniMax-M3?

When choosing a provider for MiniMax-M3, consider: output speed (for throughput-intensive tasks), latency (for interactive applications requiring quick first responses), pricing (for cost-sensitive workloads), and API features like JSON mode or function calling.
