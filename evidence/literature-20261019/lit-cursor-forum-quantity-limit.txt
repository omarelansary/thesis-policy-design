Right now, Cursor has already implemented Dynamic Context Discovery:

https://cursor.com/blog/dynamic-context-discovery

image1200×675 68.1 KB

Because of this, it’s not a problem if you turn on all tools limits.

I’m currently running more than 80 tools enabled, and there’s no warning message at all.

In older versions of Cursor, such as v1 or versions below 2.3, you would usually get a warning suggesting limiting tools to under 50. But that restriction doesn’t seem to apply anymore in the latest versions.

Cursor now optimizes token usage through MCP tools and dynamic context selection. This strategy reduces total agent token usage by up to 46.9%, which likely explains why enabling many tools is no longer an issue.

That said, other tutorials for different tools might still be correct, since not all agent harnesses or frameworks support dynamic context optimization via MCP. So keep that in mind.
