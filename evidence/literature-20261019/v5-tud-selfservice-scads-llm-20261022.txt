                    API-Zugang verwalten

Über diesen Service können Sie einen TUD:AI LLM API-Key für die Nutzung von LLMs generieren.
Der Key ermöglicht den Zugang zu verschiedenen LLM-Modellen über die TUD:AI LLM-Schnittstelle.
Die API ist erreichbar unter https://llm.scads.ai/v1/.
Die API-Dokumentation finden Sie unter https://llm.scads.ai/docs/.
Eine Übersicht der verfügbaren Modelle und den aktuellen Status finden Sie unter https://llm.scads.ai/status/.
