Note that when regex doesn't find matches (that actually happens a lot of times), the way to get the reward is to check if the full judge text response contains the string success and only if there is not success, then it searched for the failure string in the full judge text response

now see this case:

Judge response:

"Thoughts: The agent did not provide the departure time or ticket price for the earliest high-speed train. Tool call history shows only a get-current-date call (used to resolve \"tomorrow\") and no calls to station-code lookup or schedule/price APIs; the agent explicitly stated it could not retrieve station codes and therefore could not query schedules. Per evaluation criterion 1, required information must come from tool calls (not internal knowledge), and here no schedule or price data was obtained from tools. Criterion 2 (file creation) is not applicable. Because none of the required outputs (earliest train departure time and ticket price) were produced from the tool data, the task was not completed successfully.  \nStatus: \"failure\""

Reward = 1    (?)

in this case the regex pattern doesn't find any match (very common), so the success or failure is gotten from the full text, and the model said ... the task was not completed successfully ..., which contains the substring success, so it is marked as successful when the model is clearly telling that the task failed

And having the success substring, word in some part of the full answer is extremely common when you are asking a model to evaluate if a task succeeded or failed, this reward extraction mechanism is clearly insufficient and adds a lot of false positives, making Reward extraction and results extremely untrustworthy

Thank you for the reminder. This was an early implementation bug on our side, and we have fixed this issue. The fix logic is as follows:

            judge_pattern = r"Status:\s*([\S]+)"
            thoughts_pattern=r"Thoughts:([\s\S]+)Status"
            judge_match = re.search(judge_pattern, res_text, re.DOTALL)
            thoughts_match = re.search(thoughts_pattern, res_text, re.DOTALL)
            if judge_match:
                judge = judge_match.group(1).strip()
            else:
                judge = res_text
            if thoughts_match:
                thoughts = thoughts_match.group(1).strip()
            else:
                thoughts = "Thoughts extract failed."
