Summary

Several Toolathlon tasks depend on live third-party APIs or public websites. During repeated benchmark runs, we observed failures caused by rate limits, anti-bot protection, network restrictions, data drift, or evaluator-side API errors rather than model capability.

These failures can make results difficult to reproduce and may incorrectly count infrastructure failures as model failures.

Observed unstable dependencies

Several benchmark tasks can fail because of unstable external APIs rather than model capability:

Yahoo Finance / yfinance: frequent HTTP 429 and YFRateLimitError, affecting finance and exchange-rate tasks.

Google Scholar: request timeouts, HTTP 403, and CAPTCHA, affecting add-bibtex and profile-update-online.

OpenReview: api2.openreview.net may return Cloudflare ChallengeRequiredError, affecting hk-top-conf.

These failures can consume the task's turn budget or cause evaluator-side failures.

Representative Yahoo Finance error

yfinance.exceptions.YFRateLimitError:
Too Many Requests. Rate limited. Try after a while.
