CoreWeave Sandboxes Pricing

CPU and memory pricing, metered by millisecond.
Sandboxes are isolated environments for running untrusted code. CPU and memory are billed by the millisecond on CoreWeave-managed capacity, with no internet egress fees. GPU sandboxes, available in Private Preview, add per-GPU-hour charges.

CoreWeave ARIA Pricing

AI Research & Iteration Agent
CoreWeave ARIA is currently free for a limited time. After the promotional period, it will use consumption-based pricing. ARIA runs on OpenAI models. A single run may use multiple models (e.g., gpt-5.4-mini and gpt-5.5).  All plans include an Agent Token Rate of $0.50 per million tokens. This rate applies on top of model API pricing for all token types—input, cached input, and output. The combined cost is shown below:
