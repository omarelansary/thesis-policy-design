# Recovery pays at some task-population prevalence of reference-misses (population-level, strata not defined by treatment)

**Hypothesis.** [hypothesis, not a finding] Whether a recovery path (model-initiated search) is worth its price is a function of the prevalence w of tasks that need a tool outside the reference core, because value accrues only in those tasks and price accrues in all. The claim is that, for the candidate, there is a range of w, inside the range plausible for a stated task population, in which the net is positive under the pre-registered rule.

**Correction of HYP-0003 (AUTH-005 item 5a).** HYP-0003 compared the arm's overhead "in the stratum of tasks where nothing needed was removed". That stratum is defined by the exposed set, which is the treatment; the miss prevalence therefore changes with the policy and the task mix, and conditioning on it compares non-exchangeable populations (post-treatment stratification). The estimand is population-level (all tasks), the strata come from a reference partition fixed before the run and applied identically to all arms (DPR-0005 section 6), and value and price are reported weighted by w and as a function of w.

**Revision after CH-0030 (challenger, serious; conceded).** "Net above zero at some `w` in a range" is near-vacuous (at `w=1` the net is `V − P_1`) and the range has no source. The test is at the **estimated** prevalence `ŵ` (with interval) of the declared task population: falsified if, at `ŵ`, the pre-registered rule does not prefer the recovery arm to the no-recovery arm (under F1: not admissible-and-cheaper). The break-even `w*` and the curve over `w` are reported as transportability evidence, not as the falsifier. The front-matter falsifier above is superseded by this sentence; the front matter is left as written for provenance.

**Why it is plausible / unsupported.** Evidence on value: reachability is a hard gate (EXT-0053: pass^3 0.0% on tasks the retriever never surfaced; steward V6 PARTLY: rag:8 only, minimax-m3 for the decomposition) and removal without recovery loses recall (EXT-0045). Evidence on price: none measured for a search path in the stored corpus. Extra-turn effects are small in a planning benchmark (EXT-0063: "most models improve by less than 5 percentage points", V4 SUPPORTED), which is why an extra-turn control is a required arm.

**What would falsify it.** The front-matter falsifier.

**Assumptions.** The oracle stratum (tasks whose required set intersects the deferred set of the reference partition) can be computed scorer-side from the reference; the replay vehicle's single reference does not distort it badly [U].

**Alternatives it competes with.** No recovery path; HYP-0012.

**Not claimed.** A value for w; that the net is positive anywhere.
