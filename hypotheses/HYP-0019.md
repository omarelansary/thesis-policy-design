# Models recover by searching without being told to

**Hypothesis.** When a needed tool is deferred, current models start a search on their own often enough that deferral's accuracy is nearly that of expose-all, given a one-line category index in the system prompt.

**Why it is plausible.** Vendors document search as the way to reach deferred tools and advise describing tool categories in the system prompt (EXT-0131) [F, practice advice]; no per-task uninstructed initiation rate was found (FND-0037 row C-S08/UNINSTR; FND-0042) [U].

**What would falsify it.** The falsifier above, with arms: target deferred but present; target absent; a wrong tool visible; with and without the category line.

**Assumptions.** The category line is short and charged in the bill.

**Alternatives it competes with.** Expose-all; an instructed search prompt; a system trigger (V4 P3, dropped from the default).

**Not claimed.** No rate is asserted.
