# The university API exposes the bill's cache terms

**Hypothesis.** The free university API the student will use reports, per request, fresh input, cache writes, cache reads and output separately, as the providers' own APIs do (EXT-0123 for Anthropic; OpenAI usage fields per EXT-0142), so the bill can be computed as DPR-0006 defines it.

**Why it matters.** Every regime boundary in V5 (D-01) and the memory placement rule rest on the cache terms; if the API hides them, the bill must be reconstructed from list prices and token counts and the cache effects become assumptions.

**What would falsify it.** One cached request pair on each model used, reading the usage record (a reading, not an experiment).

**Not claimed.** Nothing is known about the university API in this workspace (both blind instances flag it).
