# Models initiate discovery when a needed tool is absent

**Hypothesis.** [hypothesis, not a finding] Model-initiated discovery (N3) works in practice: the model calls the search/describe interface when the tool it needs is not exposed.

**Why it is uncertain.** MCP-Atlas Table 3 reports a "No Tool Use" failure mode ("Answered from internal knowledge without calling any tool, even though tools were required"; e.g. 25.7% of diagnosed failures for Claude Haiku 4.5, 9.1% for Opus 4.7; EXT-0047, read for the table, definition per the lead's map). That concerns the task's own already-visible tools, not discovery tools; whether models invoke discovery when a tool is absent is not measured in the stored corpus (CAVEATS row 16; map). EXT-0042 (exploratory, one model, per map) shows an agent stopping itself well below its call budget.

**What would falsify it.** The falsifier above, measured as initiation rate in a forced-absence stratum with an available search interface.

**Assumptions.** Initiation can be separated from search quality; the interface is described in the same way across models.

**Alternatives it competes with.** HYP-0006 (system-side trigger); no recovery.

**Not claimed.** Either direction; the evidence is silent on discovery initiation.
