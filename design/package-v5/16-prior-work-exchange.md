# 16. Prior-work exchange: protocol, V5's needs sheet, draft amendment (V5, AUTH-020)

Status: **draft, lead, 2026-10-29** (INT-T-017, REQ-U29-01). Nothing here runs until the human approves the amendment in section 4. The human's previous, independent work is never read by the lead; it reaches this workspace only as descriptions written by an agent on the human's side (the **describing agent**). Those descriptions are **unverified prior-work descriptions**, not evidence, findings or requirements; they can change which materials V5 reuses and which parts of an experiment are skipped, never a design rule.

## 1. Protocol
1. **Blind description first.** The describing agent reads `exchange/prior-work/README.md` and writes one description per earlier experiment (`exchange/prior-work/PWD-NNN.md`, fixed fields, no conclusions, no result values). It does not see this file or any V5 file.
2. **Needs sheet frozen first.** Section 2 is committed before any description arrives; its commit hash is recorded in `exchange/prior-work/THREAD.md` as round 0. The lead compares descriptions with this frozen sheet, not with a sheet revised after reading them. A later revision of section 2 is a new revision with its reason, never a silent edit.
3. **Field-by-field match.** For every pair (earlier experiment, V5 item) the lead fills the match table of section 3: each key field Match, Partial or No, with the description's line as the pointer. **"Already done for V5" requires Match on every key field**; anything less means at most "reuse the materials, run again for V5's scope".
4. **One channel.** The two agents talk only through `exchange/prior-work/THREAD.md` (append-only, one message per entry, format in that file). The lead asks questions about scope and materials, never for result values; a result value crosses only when the human approves that one question in the thread.
5. **Disagreement.** If the describing agent holds that an experiment is already done and the lead's table says it is not, each side states its position once more with pointers; after two rounds the lead writes both positions for the human, who decides. Neither agent decides, and nothing is averaged.
6. **What may cross into V5.** (a) The lead's match table and its reading [I]; (b) materials (task sets, tool catalogues, user histories, harness or logging code, graders) only when the human copies them into the workspace with an intake record (`requirements/intake/README.md`); (c) never the earlier results, conclusions or numbers as evidence for a V5 claim. The ledger's existing rows XE-01..XE-09 (results relayed earlier, UNVERIFIED, barred) are unchanged by this protocol.
