## 4. What changes in V5
- **Adopted (new recommendations in `04` section 6, registered in `06`):** V5-R10, append discovered tools as tiered entries (name and one line first, schema on request), the exposé's fixed levels as the candidate definition; V5-R11, log churn of the visible set and offered-set recall, and run an oracle-registry ablation, in the loop (`05`).
- **Added to the loop (`05`):** eviction of appended tools beside masking (P4, gated by the rewrite arithmetic); the no-match rule and validation-gated expansion as recovery options (P3); enriched searchable text as an optional offline step if lexical search misses.
- **Parked or dropped:** topic-shift reset (park); exploration and planner stages, logprob routing, vLLM serving and the brief's acceptance criteria (drop).
- **Unchanged:** the policy graph (`04` section 3), DPR-0007's structure, the bill criterion.

## 5. What this check does not show
It does not show that any idea works: the verdicts compare ideas with stored evidence and with V5's arithmetic. D-03's compact fraction is an assumption. The exposé's and brief's claims about benchmarks and prior papers were not re-read. Whether tiered entries keep accuracy, whether eviction or topic-shift handling matters on long runs, and whether enriched text helps are all untested.
