## 2. Property cards (condensed by the lead)
- **ATRBench** (arXiv 2605.28108 v3; repo BUPT-GAMMA/ATRBench, one commit). 20 synthetic personas, 568 learning sessions, 284 frozen test sessions (no asking). 6 domains, 74 author-built tools; each session exposes its domain (9-17 tools plus a confirmation tool). Simulated, native function calling. Learning sessions with gpt-5.4 user simulator; no wall-clock gap, generated temporal order. Programmatic tool-level scorer; judge only in construction QC. Own runner; memory as a cross-session context block in the next session's system prompt (App. B.4). App. F: list price and cache-discounted totals, hit rate per cell. Code Apache-2.0, personas CC BY 4.0. Non-oracle runs need OPENAI_API_KEY and GEMINI_API_KEY; custom endpoints undocumented.
- **Momento** (arXiv 2606.00832v1, 30 May 2026; repo ninoaddict/momento, 2 commits; HF dataset). 161 human-annotated tasks; prior sessions "generated via human role-playing" (§2.3); 26 tools, one restaurant platform; Docker PostgreSQL (pgvector), per-session memory in the DB, state reset per trial. Multi-session, "temporally separated", time modelling not described; simulator Qwen3.6-35B-A3B with evolving latent states. DB-state check, Tool Recall, unspecified Output metric; all three must pass; Pass@k, Pass^k. LiteLLM, any OpenAI-compatible endpoint. No cost. Code Apache-2.0, data CC-BY-SA.
- **VitaBench 2.0** (arXiv 2605.27141v1, 26 May 2026; repo meituan-longcat/vitabench-2.0, 9 commits). 56 users, 771 subtasks, at least 10 per user in sequence; 66 tools in three domains (inherited); prior history exposed; memory in the system prompt; backends null, groundtruth, full_context, rewrite, rag, rag_cache; rubric evaluator gpt-4.1, agreement not reported; simulator gpt-4.1; four runs (Avg@4, Pass@4, Pass^4); any OpenAI-compatible endpoint; MIT. No cost.
- **ETAPP** (arXiv 2503.00771 v2, ACL 2025; repo hypasd-art/ETAPP, 4 commits). 16 generated profiles x 50 instructions = 800; 33 APIs plus search_tools and get_tool_doc (35); "simple sandbox", some RapidAPI data, news by gpt-4o; 9-day constructed history; single query per test; GPT-4o judge with key points, agreement on 96 points; ReAct, FC, E-ReAct, with or without retrieval; tokens per instruction only; no licence shown; needs OpenAI and DeepSeek keys and a JDK.
- **MPT** (arXiv 2604.17886 v1 20 Apr, v2 8 Sep, v3 14 Oct 2026; anonymous repo showed no files). 4,695 instances, 459 dialogues, 6,961 sessions, 95,523 turns, about 15.2 sessions per dialogue; 13 functions, 16 function-parameter pairs, 7 functions added at inference; histories composed from SGD, DuRecDial 2.0, HomeBench; no gaps; F1 scorers; baselines full history, RAG, Mem0, LangMem, A-MEM; memory tokens only; paper CC BY 4.0, mixed corpus licences.
- **Mem2ActBench** (arXiv 2601.19935 v1; anonymous repo). 400 tasks from 2,029 sessions (429 used); catalogue size not stated; LLM-generated from ToolACE and BFCL v3 with OASST1 noise; offline generation; F1, BLEU-1, Tool Accuracy; no licence.
- **EvoMemBench** CrossEp-Tool (arXiv 2605.18421 v2; repo DSAIL-Memory/EvoMemBench). 800 tasks (200 per category) rebuilt from BFCL multi-turn with implicit references; tool counts not stated; token usage without cache split; no licence.
- **PEToolBench** (arXiv 2502.18980v1, Findings ACL 2025; repo travis-xu/PEToolBench, Apache-2.0). 7,454 RapidAPI tools in 46 categories, candidate set N=10 per test; 12,000 instances; simulated histories (gpt-4o-mini).
- **PTBench** (arXiv 2505.04072 v1; repo hyfshadow/PTBench, no licence). 360 synthetic APIs; 80 users; 1,083 test instances; OpenAI API only.
- **APOLLO** (Findings ACL 2026; repo zhiyuanc2001/APOLLO). Files `task_tool8_turn4.json` ("4 sessions"); details not stated; local vLLM.
- **DolphinBench** (Mem0; arXiv 2609.24971 v2, 22 Sep 2026). Interested party (authors listed as "of Mem0"; Mem0 configuration best). 3 personas x 200 tasks; histories about 500k user-message tokens, generated; tools simulated; deterministic checks plus GPT-5.6-Sol judge, no agreement; tasks verified to succeed with history and fail without; total ingestion plus test cost and latency required; cache not mentioned; no licence.
- **BFCL v4 memory** (Gorilla blog, 2025-07-17): snapshot after each session, final snapshot loaded; KV (BM25+), vector (FAISS), recursive summary (10,000 characters); "150+ questions".
- **Evo-Memory** (arXiv 2511.20857v1): streams of existing datasets; ToolBench only for tools; table discrepancy (C29); no code found.
- **MemoryArena** (arXiv 2602.16313v2): 701 task groups in 4 environments, each subtask a separate session; small catalogues; no gap; no licence.
- **MemoryAgentBench** (arXiv 2507.05257v4): chunk injection; no tool-use tasks found (corrects the landscape scout E listing); MIT code, CC BY 4.0 data.
- **LongMemEval** (arXiv 2410.10813 v2; repo xiaowu0162/LongMemEval, MIT, 45 issues; 2025/09 cleaned sessions; LongMemEval-V2 arXiv 2605.12493 not read): not a tool benchmark; reference for constructing returning-user histories.

## 4. Not found
No benchmark with a wall-clock gap tied to cache lifetime; no benchmark combining a large catalogue (hundreds) with multi-session memory-dependent tool use (largest per session: VitaBench 2.0, 66; PEToolBench 7,454 total but 10 per test); no real-user histories; no extension of tau-bench, ToolSandbox or MCP benchmarks into multi-session; no methods paper on extending single-session benchmarks (observed recipes: filler plus timestamps C34; snapshots C32; chunk injection C31; explicit-to-implicit rewriting C27; stream ordering C29; composed users C6; chained subtasks C30; with failures: no gap model, filler mismatch C35, thin validation C27, stateless simulators C14, tasks solvable without history unless checked C37). Not read: APOLLO paper, LongMemEval-V2, AgentMemBench, anonymous repos, dolphinbench.ai, HF cards, tails of long pages. No independent criticism for ETAPP, MPT, Mem2ActBench, Momento, VitaBench 2.0, ATRBench.

## 5. Possible wrong assumptions
- P1 requires a catalogue above n*, but every memory-dependent tool benchmark has 13-74 tools (9-17 per session in ATRBench); padding needed, a design decision with a reason.
- ATRBench and VitaBench 2.0 inject memory into the system prompt; V5 appends seeds after a cached prefix; native use would put memory in the prefix; harness replacement is a modification.
- Personalised-tool benchmarks score which parameter or similar tool the user prefers, not whether a tool needed before is offered again; V5's h has no native definition; Momento's Tool Recall and DolphinBench's tool-called checks are closer.
- No native gap model: cache-lifetime gaps are added by the harness in every case.
- Closed-model dependencies (ATRBench, ETAPP, PTBench, VitaBench, DolphinBench); replacing judges or simulators invalidates published agreement; Momento and VitaBench 2.0 most compatible.
- Memory systems often do not beat full context or plain retrieval (MemoryArena, EvoMemBench, ConvoMem): P1 may show a bill difference without an accuracy gain.
- DolphinBench's with/without-history check is the only construction test found that guarantees memory is needed.
