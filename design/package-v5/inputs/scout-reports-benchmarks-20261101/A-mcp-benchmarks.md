## 2. Property cards (condensed by the lead)
- **MCP-Atlas** (Scale AI; arXiv 2602.00933v1, 31 Jan 2026; repo scaleapi/mcp-atlas, image ghcr.io/scaleapi/mcp-atlas:1.2.7, CHANGELOG one entry "v2.0.0"; HF dataset no revision on card; read 2026-11-01). Authors run the leaderboard (interested). Single-turn "tool-use competency with real MCP servers". 1,000 tasks, 500 public, 500 held out "to prevent overfitting"; card 500 rows, split "train", 15.6 MB. 36 servers, 220 tools (README says 307); "10-25 tools per task, including 3-7 required tools and 5-10 distractors"; targets from 2 or more servers. Docker sandbox, version-pinned servers; "20 need no setup, 11 require API keys, and 5 require API keys plus data setup"; containers "restarted per run"; read-only operations. Loop up to `--max-turns` 256, `--max-tool-calls` 100. Claim-based LLM judge: Gemini 2.5 Pro in the paper, 78% agreement with majority human vote, threshold 0.75; README default `gemini/gemini-3.1-pro-preview`. Columns TASK, ENABLED_TOOLS, PROMPT, GTFA_CLAIMS, TRAJECTORY. Own multi-turn loop (rewritten to TypeScript in v2.0.0); `LLM_BASE_URL`, `LLM_API_KEY` required; request-layout control not found. No tokens or cost. Code MIT, data CC-BY-4.0. Open-weight Table 3 pass %: GLM-4.5 Air 34.0, Kimi K2 Instruct 23.9, Qwen3-235B-A22B 12.0 (v1, Gemini 2.5 Pro judge).
- **MCPMark** (arXiv 2509.24002v1, 28 Sep 2025; repo eval-sys/mcpmark; v1-0905 logs deprecated, "Verified" default). 127 tasks over 5 servers (Filesystem 30, Notion 28, Playwright 25, GitHub 23, PostgreSQL 21), 38 initial states; "55 MCP servers" in §2.1 looks like a typo. Sandboxed reset; Notion and GitHub need accounts; Playwright "@latest". About 16.2 turns, 17.4 tool calls per task; cap 100 turns, 3,600 s. Programmatic verification on final state. MCPMark-Agent: LiteLLM and MCP SDK loop, OpenAI function format. Table 9 per task: gpt-5-medium 627.66K input, 21.91K output, $1.00, 14.71 turns; Kimi-k2 931.50K input, 5.01K output, $0.57, 26.95 turns; no cache figures. Paper CC BY 4.0. Open-weight pass@1: qwen3-coder-plus 24.80, kimi-k2 21.85, deepseek-v3.1 16.73, glm-4.5 15.55, gpt-oss-120b 4.72.
- **Toolathlon** (arXiv 2510.25726v2, 26 Feb 2026; repo hkust-nlp/Toolathlon). 108 tasks; 32 applications, 604 tools; 69.9 tools per task (28-128). Containers with initial states (67% of tasks), some local replacements; issues report public services inaccessible. 20-26.8 turns, cap 100. Deterministic scripts. OpenAI Agents SDK v0.0.15 harness; outputs truncated at 100K characters, 10K paging; all cleared except the last 10 turns at limits; overlong outputs in 15-35% of trajectories. Most models 5-10K output tokens, under $1 per task, caching enabled (§5.3), no hit rate. Issue #87 "LICENSE file is missing". Best open model DeepSeek-V3.2-Exp 20.1%, best overall 38.6%.
- **TheMCPCompany** (arXiv 2510.19286v1; Microsoft per alphaxiv, snippet only; repo not opened). 175 tasks from TheAgentCompany plus 17 Azure tasks. 18,505 tools (Azure 16,837, GitLab 1,085, RocketChat 520, Plane 52, ownCloud 11) built from REST APIs. Docker services plus live Azure subscription (Terraform per task). Arms: browser baseline, tool finder (gateway server with search and invoke), oracle tools. Checkpoint partial credit (50/50); Azure none. OpenHands CodeAct 0.48.0, modified system prompt. Dollars per task, no raw tokens; no open-weight models.
- **MCPVerse** (arXiv 2508.16260v2, 11 Oct 2025; repo hailsham/mcpverse, `mcpverse_time_invariant_v1.1.csv`; SenseTime). 250 tasks, three levels. 65 servers, 552 tools; Standard 32 servers, 220+ tools (about 44k tokens, for 64k context); Max-Scale about 140k-147k tokens; Oracle mode. Live services, keys needed; 2025.12.22 note: some servers deprecated, questions "can no longer be reproduced"; v1.1 time-invariant only. Hybrid scorer: LLM judge (QwQ-32B in paper, Qwen2.5-72B in repo) plus scripts. CAMEL loop; prompt-based mode puts definitions in the system prompt. Schema tokens reported, no cost. Apache-2.0. 7 stars, 27 commits.
- **LiveMCPBench** (arXiv 2508.01780 v1, 3 Aug 2025; a v2 26 Feb 2026 not read; CAS ICIP). 95 tasks; 70 servers, 527 tools (keyless). Agent has `route` retrieval and `execute`. Key points per task; gold tool lists not found. Live, time-sensitive (runs 20-27 Jul 2025). LLM judge DeepSeek-V3; human agreement 81%, 81.05%, 78.95% in different places. MCP Copilot Agent (ReAct). Cost only as log-price Pareto plot. Paper CC BY 4.0.
- **MCP-Universe** (Salesforce; arXiv 2508.14704v1; repo SalesforceAIResearch/MCP-Universe). 231 tasks; 11 servers, 133 tools; §4.5 stress adds 7 servers, 94 tools. Live APIs, keys. Execution-based evaluators, 84 (4 format, 32 static, 48 dynamic). ReAct. No cost. Licence not found. Open-weight SR: GLM-4.5 24.68, Qwen3-Coder 19.91, Kimi-K2 19.05, Qwen3-235B 18.18, DeepSeek-V3 14.29, GPT-OSS-120B 11.26.
- **MCP-Bench** (Accenture; arXiv 2508.20453v1). 104 tasks (56/30/18 by servers), synthesised with o4-mini, human-inspected. 28 live servers, 250 tools; 10 distractor servers per task, "100+ additional tools per instance". Rule metrics plus o4-mini rubric judge, five shuffled prompts. Plan-execute-compress loop, 20 rounds. Licence not found. Open-weight: gpt-oss-120b 0.692, qwen3-235b 0.678, glm-4.5 0.668.
- **MCP-AgentBench** (USTC, arXiv 2509.09734): 33 servers, 188 tools, 600 queries, judge "MCP-Eval" (snippet only).
- **MCPAgentBench** (arXiv 2512.24565, v1 read, v3 exists): 180 tasks from 841; simulated servers (GPT-4o stubs, expert review); K=20 candidates; deterministic; match to one golden solution; TEFS; open-weight models tested.
- **MCPToolBench++** (Ant Group; arXiv 2508.07575v1): 1,509 instances; 87 tools, 6 categories; Table 1 schema tokens about 25K total; candidates per query not stated; AST plus Pass@K real execution.
- **LiveMCP-101** (Zoom, Duke; arXiv 2508.15760v1): 101 tasks; 41 servers, 260 tools; "15 MCP servers and 76-125 tools available" per task; validated plans; GPT-4.1 judge Likert, κ above 85% results, 78% trajectories; ReAct, 30 rounds; open-weight TSR: Qwen3-235B 22.77, Qwen3-32B 18.81, Llama-3.3-70B 1.98.
- **MCPEvol-Bench** (arXiv 2607.14642v1): 201 tasks; 123 servers, 1,272 tools; 25.90 tools in context per task; 11 mutation operators at tool, parameter and description level; DeepSeek-Chat rubric judge averaged over 5; "approximately 0.26$" per evaluation; code not found.
- **MCP-RADAR** (arXiv 2505.16700 v2): 507 tasks (Table 1 sums to 515); 49 tools, own mock servers for Email and Calendar; exact match; small catalogue.
- **MCPEval** (Salesforce; arXiv 2507.12806v2): auto-generated tasks, five domains; ground truth from gpt-4.1; "relies entirely on synthetic data".
- **ScaleMCP** (PwC; arXiv 2505.06416v1): 5,000 servers, 140,000 templated queries; retrieval study, release not stated.
- **MCP-Zero** (arXiv 2506.01056v4): 308 servers, 2,797 tools; "cuts prompt length by 60-98%"; 6,308.2 vs 111.0 tokens; closed models only.
- **Snippets only:** DynamicMCPBench (arXiv 2607.20531; framework; 24 models, 121 servers, 750 tasks; agreement 0.76); not read: arXiv 2607.28367, 2609.09218.

## 5. Possible wrong assumptions
1. No benchmark reports cache fields; every candidate's harness must be replaced (MCP-Atlas `enabledTools` per task; MCPVerse prompt-based definitions in the system prompt; Toolathlon clears outputs).
2. Live services and keys are common; time-varying outputs can break prefix identity across arms; paired-arm stability is a hard requirement; P5 can avoid tasks.
3. Floor and ceiling: MCPMark gpt-oss-120b 4.72%, MCP-Universe 11.26%, MCP-Atlas 12.0-34.0%; MCP-Bench compressed at 0.65-0.69.
4. Per-task catalogues are small (10-25 MCP-Atlas; 76-125 LiveMCP-101; about 70 Toolathlon); only TheMCPCompany (18,505) and MCPVerse Max-Scale (552, about 140k tokens) reach deferral regimes; R-large needs padding or construction; padding is a modification that changes accuracy (A29).
5. Scorer validity and run variance (A9, A10, A23): paired design, repeats, and a judge-agreement check before loop readings.
6. Leaderboards disagree with reproductions (A26).
