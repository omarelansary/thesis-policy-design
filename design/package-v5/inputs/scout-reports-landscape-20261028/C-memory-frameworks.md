## 5. Contradictions, failures, costs more than it saves

1. **Memory systems did not beat the plain baselines on accuracy, in their own tables or in a third party's.** Mem0 paper full-context 72.90 against Mem0 66.88 and Mem0g 68.44; MIRIX full-context 87.52 against 85.38; third-party testbed RAG at $0.65 and 78.31% against mem0 at $5.43 and 81.08%, full-context $10.22 and 77.16% (C1, C10, C11, C21, C29). This supports V5's "accuracy nearly the same, lower bill" criterion and its plain-file memory baseline (C12). Whether it holds on tool-use tasks rather than LoCoMo-style question answering is not shown by any of these pages.
2. **UPDATE and DELETE removed by Mem0** because they destroyed information (C3). V5's W is append-style, so it is consistent, but any plan to let W overwrite earlier tool entries would run against this.
3. **Graph memory cost more and scored lower in the one independent test** (Graphiti $6.95 and 56.03%, cognee $2.99 and 55.27%, C11). V5 does not use a graph; this supports leaving it out.
4. **Hot-path memory search can be very slow** (LangMem search p95 59.82 s, C19), which is a reason V5 reads once at session start and writes after the session.
5. **Benchmark reliability.** LoCoMo has reported answer-key errors and judge leniency (C28, C9), vendors disagree on scoring (C9), and the same system's score differs between papers (C10). V5 should not use a published LoCoMo number as evidence for any choice.
6. **Staleness.** Superseded memories remain in Mem0's default results unless the caller asks for current facts (C25); Zep invalidates old edges with bi-temporal timestamps (C7). A V5 memory that names tools to seed needs the S1 permission set and a validity check at seed time. No framework read does this for tools.
7. **Memory in the system prompt versus V5's rule of per-user content after the shared prefix (V5-R06).** Letta places blocks and root files in the system prompt (C13, C14) and MIRIX injects into the system prompt (C21). For the shared prefix across users that is the opposite of V5-R06. None of the pages say what this costs in cache terms.
